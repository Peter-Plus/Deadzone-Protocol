# 大型交互物模型与动画

状态：2026-10-05 用户确认美术项验收完成，三种设施模型、三段节点动画及附魔台自身反馈已验收，移入完成项；玩法尚未接入。负责附魔台、大型神秘宝箱、空投箱三类世界交互物的模型与交互动画，以及附魔台自身的状态材质和使用反馈。资产完成不代表玩法已经接入。

## 1. 目标与依据

玩家应能从外观识别设施用途，从动作辨认一次交互正在发生或已经完成。三类物体均是世界设施，不可携带。

- 项目根目录：`G:\Game\Fire\Deadzone Protocol`。先读根目录 README、AGENTS 和 [世界交互规则](../../../../Design/World/WorldInteractions.md)。
- 附魔规则以 [Elements](../../../../Design/Combat/Elements.md) 为准；交互与物品列表以 [UI](../../../../Design/UI/UI.md) 为准。
- 正式源库为 `G:\Game\Fire\ForgeKit\assets\FSA(项目使用)`，遵循 [ForgeKit 资产生成规则](../../../../../ForgeKit/rules/ASSET_RULES_FOR_AI.md)。现有模型、动画格式见 [模型资产使用说明](../../../../Assets/模型资产使用说明.md)。
- 本项不包含可携带三类军备箱、信号枪模型、建筑、铁门、首领结界或混沌尖刺。不扩大为环境建筑整包制作。

## 2. 模型与外观

| 交互物 | 外观建议 | 结构和状态要求 |
| --- | --- | --- |
| 附魔台 | 腰部附近高度的黑灰色异变石台，粗糙石质底座包裹少量残旧金属；台面有凹槽和断裂的环形刻纹，中心悬浮小块晶体。整体像灾难力量侵入现实形成的设施，不做成普通工作台，也不做宏大的神庙建筑 | 一套共用台体，独立晶体与可活动环片；提供普通可用、火封印、毒封印、解锁可用、使用耗尽状态。火／毒差异通过附属表现区分，不各做一套不兼容台体；耗尽后台体保留、晶体落低或环片收拢，发光明显减弱 |
| 大型神秘宝箱 | 明显大于可携带军备箱的厚重旧金属箱，暗色箱体、加固包角，少量异变纹路或低亮光缝突出稀有感 | 完整内腔、独立箱盖与锁扣、正确铰链轴心；关闭、开启过程、开启后均可查看。箱内不固定摆放武器或奖品模型 |
| 空投箱 | 工业／军用运输箱，坚固外框、运输护角、醒目的高对比识别色与运输标识；远看即可与神秘宝箱区分 | 完整内腔、独立箱盖与锁扣。可与神秘箱复用结构思路，但应有不同轮廓和材质；首版交付落地箱体及开箱动画，不额外要求飞机、降落伞或完整空中运输演出 |

以上是首版外观方向，可在保持功能辨识的前提下调整细节。模型沿用米制、+Y 向上、+Z 前方，原点在底面中心。提供实际尺寸、正面交互参考点、简化碰撞参考及活动部件最大扫掠范围，供摆放时预留空间。模型应可在合法平整放置面使用，不用装饰遮挡交互面。

## 3. 必须交付的动画

| 动画 | 动作要求 | 时长与结束状态 |
| --- | --- | --- |
| 附魔台附魔 `Enchant` | 中央晶体抬升、环片轻微展开或旋转，力量向台面中心汇聚，随后晶体回落、环片收拢；火／毒各有可区分的同步光效，可共用节点动作 | 建议约 2～3 秒，单次播放，结束衔接耗尽状态。具体时长属于表现建议，不新增强制玩家站定或等待机制 |
| 神秘宝箱开箱 `Open` | 锁扣解开，厚重箱盖抬起，有适度重量感和缓冲 | 建议约 1～1.5 秒，单次播放，末帧保持开启，不自动回到关闭姿态 |
| 空投箱开箱 `Open` | 运输锁扣释放，箱盖抬起并固定；机械感与神秘箱有区别 | 建议约 1～1.5 秒，单次播放，末帧保持开启，不自动关闭 |

至少交付三段独立节点动画。附魔台若采用火／毒两段动作变体，分别登记；也允许共用一段动作配两套效果。台体自身须有可见运动，不能只提交一张发光材质代替附魔动画。

另提供附魔台火／毒封印消退到可用、可用切到耗尽的状态表现，可由材质／特效切换实现，不强制每种状态都增加独立动画文件。普通可用台与解锁可用台可共享外观，但须记录两种玩法状态均可正确映射。

## 4. 动画文件与 ForgeKit 支持

交互物可以用节点动画交付为独立 `.anim.glb`，无须做成人形骨架。模型文件保存箱盖、锁扣、晶体、环片等稳定命名节点；动画文件包含匹配节点和一段动画，通过同名节点绑定。模型根节点固定，活动部件围绕正确枢轴运动。

**当前工具限制必须实际解决：**现行 ForgeKit `animation.v1` 规则主要支持固定角色与 FPS 双臂骨架，不能默认它已经支持任意箱盖或晶体轨道。执行者须先检查当时最新实现；如仍缺少通用交互物节点动画，应在 ForgeKit 内补齐最小必要的验证、导出、预览与绑定支持，记录契约并验证不破坏既有角色／双臂流程，再产出正式动画。不得借用人形手臂节点冒充箱盖，也不能只改文件后缀宣称动画完成。

- 单纯节点位移、旋转、缩放写入 `.anim.glb`；粒子、光晕和状态材质作为独立效果资源／配置交付。不得假定它们会自动包含在普通动画轨道中。
- 三段必需动画都要在预览中绑定到正式模型实测，不能仅在生成脚本中存在。
- 记录各片段时长、播放方式、末帧处理及效果同步参考时间。同步参考仅服务表现，不决定附魔消耗、奖励生成或成功判定。
- 如提供源 `*.anim.json`，必须与实际新增或既有编译契约一致，并交付可复现的生成方式。

## 5. 玩法边界

- 附魔台一局使用一次，普通台及解锁后的首领台均可使用火／毒晶核；火封印台解锁后不能仍只表现为火专用台。首领被击败后解锁原台，不能叠放新台；被混沌吞噬不自动解锁。
- 附魔动画由已确认的附魔结果驱动，不自行消耗晶核、改装备或召唤首领。不要求把任意玩家装备自动复制到台面；首版以台体与能量运动表达附魔。
- 两类箱子首次开启要求附近无存活敌人，条件由玩法判断；动画不能自行开放奖励。开启后保持开启，离开返回、切换显示或恢复状态时直接恢复正确姿态，不重播开箱或重抽奖励。
- 箱内剩余物品通过附近列表展示，未领取内容仍保留；无需为每件物品制作箱内摆放。领空后仍保持开启，可用已有状态表现，不另加自动关闭动作。
- 只有 ESC 菜单暂停；附魔界面和交互动画不额外暂停世界。资产不内置冻结玩家、免伤或镜头强制演出。
- 空投由信号枪请求并约 20～30 秒后落地，实际落点与下降位移由世界逻辑控制，不把等待时长或世界落点烘焙进开箱动画。落点标记继续由物品特效工作项负责。

## 6. 交付与验收

建议模型放在 `Assets/models/world/interactables/`，独立动画放在 `Assets/animations/world/interactables/`，设施自身特效放在 `Assets/effects/world/interactables/`。最终路径以正式源库和项目归档规则为准，逐文件登记至 [模型动画资产配置表](../../../../Assets/模型动画资产配置表.md)，补充 [模型资产使用说明](../../../../Assets/模型资产使用说明.md) 中的交互物绑定契约。特效按 Assets 目录规则登记，不记为 UI 图标。

验收至少覆盖：

1. 三种设施在玩家尺度下外观可辨，所有要求的静态状态完整；附魔台的火／毒封印和耗尽状态可区分。
2. 三段动画分别检查起点、中间关键姿态和末帧，无明显穿插、箱盖脱轴或根节点漂移；箱体有内腔，打开后不出现缺面。
3. 两个同类实例可独立播放、切换状态，节点或材质变化不串到另一个实例。
4. 动画停止后与重新载入模型时，都能正确恢复开启／耗尽状态；开箱末帧不会自动复位。
5. 在 ForgeKit 正式流程完成生成、校验和预览，记录实际命令与结果；若扩展工具链，执行其要求的相关检查。项目运行时若未接入，使用说明须明确写明，不把预览通过写成玩法验收通过。

美术项已验收。按制作人要求不保留独立交付报告和项目内验收预览目录；正式文件清单、动画及效果契约继续维护在 Assets 配置表和使用说明中。
