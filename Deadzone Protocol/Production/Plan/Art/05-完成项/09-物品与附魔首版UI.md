## 交付与边界

- 按 [UI 目录说明](../../../../Assets/ui/README.md) 交付透明背景 PNG 或可内嵌 SVG，保证小尺寸识别度，不引用远程资源。
- 消耗品、弹药、材料、军备箱、信号枪与金币图标放在 `Assets/ui/icons/items/`，护具及背包图标放在 `Assets/ui/icons/equipment/`；逐文件登记到 [UI 资产配置表](../../../../Assets/UI资产配置表.md)。
- 本单不包含附魔台及其他大型场景交互物的美术制作；新工作项与环境拆分另行整理。
- 首版十把武器图标见 [独立工作项](../05-完成项/13-首版十把武器图标.md)。
- 层数、抗性数值、倒计时及阈值由 UI 动态显示；毒伤与灼烧的 HUD 基础图标已按 [独立工作项](../05-完成项/08-毒伤灼烧HUD图标.md) 验收完成，不重复列为本单交付。
