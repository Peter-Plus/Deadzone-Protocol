# 毒伤与灼烧 HUD 图标

状态：2026-10-05 制作人验收完成；两张透明 PNG 已交付，运行时未接入。

## 面向策划

毒伤与灼烧使用小方形图标，右下角数字显示层数，360° 扇形阴影分别表示当前层毒素／每层容量（参考 100）和剩余时长／当前层最大时长。同组另有翻滚与暗影双刃冷却图标；样式见 [UI 美术规范](../../../../Assets/ui/README.md)。

## 资产约束

- 建议交付透明背景 PNG 或可内嵌的 SVG，各状态一个基础图标；统一放在 `Assets/ui/icons/status/` 并登记到 [UI 资产配置表](../../../../Assets/UI资产配置表.md)，实际导入方式由 UI 模块确定。
- 小尺寸下仍能区分毒与火，不只依赖颜色；图标不预先烘焙层数或进度遮罩，由 HUD 动态叠加。不制作状态名称、秒数或通知条背景。
- 不引用远程字体、贴图或图标库，保持可双击运行的自包含 `Play.html` 入口。

## 建议

先交单色轮廓稿，在实际 HUD 尺寸下验收识别度后再加细节。
