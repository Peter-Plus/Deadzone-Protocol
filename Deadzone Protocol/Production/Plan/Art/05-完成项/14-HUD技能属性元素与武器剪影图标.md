## 参考与制作要求

- 遵循 [UI 美术规范](../../../../Assets/ui/README.md)，制作前查看 [HUD 参考样图](../../../../Assets/ui/concepts/2026-10-05-style-comparison/D-hud-v2.png)。样图用于造型与风格参考，不直接裁切图标，也不照搬其文字、按键和数值。
- 本单 25 张均按制作人要求由 Codex 使用 AI 生图提前制作，不以程序 SVG 或已有图标自动轮廓提取替代正式交付。
- 空槽图标统一使用象牙白简洁轮廓，表示槽位类别，与已装备时的物品图标或武器剪影区分；弱化显示由程序控制，两个主武器空槽不为区分编号强行设计不同武器类型。
- 武器剪影以 `Assets/ui/icons/weapons/` 中十张已验收图标的识别特征为参考；暗影双刃参考 v3 X 形交叉定稿。普通枪械朝左、横向侧视；手雷竖置，双刃保留成对特征。
- 现有武器插画的透明通道可能包含辉光、残留或半透明细节，不能假定直接填白即可得到干净剪影。独立生成简洁、实心的 HUD 轮廓，保留主要识别结构，省略材质、辉光和细碎纹理；不覆盖原物品图标。
- HP／SP／ST 与武器剪影采用象牙白 `#E8ECEF`；技能及影元素遵循规范的克制语义色。翻滚与 ST 即使同为人形，也要在小尺寸下能区分动作。
- 不烘焙卡片底框、按键、名称、数量、属性条、层数或冷却扇形；这些由运行时叠加。

## 交付与验收

- 交付独立 RGBA 透明 PNG。技能、属性、元素、消耗品与护具空槽建议 128×128；五个武器空槽建议 512×256；武器剪影建议 512×256，以统一画布和视觉比例适配横向槽位，手雷与双刃不强行拉伸。
- 建议目录：`Assets/ui/icons/skills/`、`attributes/`、`elements/`、`weapon_silhouettes/`、`slots/`。建议命名分别为 `ui_skill_roll`、`ui_skill_shadow_assault`、`ui_attribute_hp/sp/st`、`ui_element_shadow`；武器使用 `ui_weapon_silhouette_<现有武器英文后缀>`。空槽使用 `ui_slot_primary_1/primary_2/secondary/melee/throwable/consumable/helmet/armor/boots`。上述路径均已有对应交付文件，实际规格以 UI 资产配置表为准。
- 技能／属性／元素／消耗品与护具空槽按 24、32px 检查；武器剪影与武器空槽在约 96×48 与 64×32px 下检查识别度，最终随实际 HUD 槽位复核。
- 在深色、浅色和彩色背景及透明棋盘上检查：背景完全透明，无残留色块、脏边、游离像素或大片半透明雾；仅轮廓边缘保留必要抗锯齿。主体不裁断、不贴边，十把武器视觉重量协调。
- 实际交付后逐文件登记 [UI 资产配置表](../../../../Assets/UI资产配置表.md)，分别记录美术验收和运行时接入状态；不得将待验收资产计为已验收。
