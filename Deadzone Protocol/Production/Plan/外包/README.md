## 使用方式

1. 按工作项中的“需上传文件清单”，从项目根目录 `G:\Game\Fire\Deadzone Protocol` 选择文件上传给网页版 ChatGPT。
2. 将该工作项全文作为委托说明发送。
3. 要求对方按“必交成果”返回 Markdown 文件；不要求对方直接编辑项目正式文档。
4. 制作人审阅、删改并确认提案后，再交给 Codex 将采用的内容整合进 `Design/`、开发计划或实现任务。

上述原始委托保留供追溯；继续设计或开发时须读取当前 Design，避免旧委托与其他已采纳内容冲突。制作人原始回复保留在本目录的“制作人回复”中。
