资产分类和交付入口见 [Assets 目录说明](../../Assets/README.md)；UI 图标统一存放在 `Assets/ui/icons/`，登记到 [UI 资产配置表](../../Assets/UI资产配置表.md)。

## 直接打开游戏

双击项目根目录的 **Play.html**。默认进入第一人称训练场，文件内已包含 Three.js、Rapier WASM、所需模型动画、配置与样式，不需要 npm、Node、本地服务器或网络；需要桌面浏览器支持 WebGL 2 / WebAssembly。可将这个约 5 MB 的文件单独复制到其他目录使用。

Play.html 是生成产物，不能手工编辑；配置或源码修改后由开发者重新构建即可。index.html 是开发模板，不是双击入口。

制作人已完成基础场景及本轮第一人称训练场验收。自动化浏览器禁止 file://，仅能在 HTTP 下验证同一份自包含产物；此限制来自测试环境，不是要求用户用服务器启动。

## 开发者工作方式（可选）

在 PowerShell 执行：

```powershell
cd 'G:\Game\Fire\Deadzone Protocol'
npm ci
npm run dev
```

仅开发和构建需要 Node.js 22 或以上；首次 npm ci 需要网络。可选开发服务地址是终端显示的 http://127.0.0.1:5173，仅允许本机访问。结束时在服务终端按 Ctrl+C。

如果该端口被占用，esbuild 可能选择其他端口，以终端输出为准。修改 src 下代码/JSON 后会重新构建开发页面，需手动刷新页面；修改 index.html 后重启开发服务。开发服务不会自动更新根目录 Play.html，需要 npm run build。不要直接在 dist 里改代码。

## 页面操作

默认训练场：点击“开始 / 继续 · 锁定鼠标”；WASD 移动，鼠标观察，空格跳跃，左键或 F 射击，R 换弹，ESC 暂停。全部击倒 5 个橙色靶子后在菜单重新开始。鼠标锁定失败时用“窗口模式进入”，右键拖动或方向键观察。

详细操作、调参和本轮边界见 [FirstPersonRange.md](FirstPersonRange.md)。

## 旧基础诊断场景

在训练菜单点击“打开基础工程诊断场景”，或给 Play.html 地址加上 #foundation：

- “暂停模拟 / 继续模拟”：观察探针和模拟步数是否停止/恢复。
- “按种子重启”：按输入种子创建新局；相同种子应得到相同标记物布局，时间重新计数。不同种子改变布局。
- 页面切到后台时自动暂停，回来后手动继续。
- “丢弃的追帧时间”表示严重卡顿超过每帧追帧上限的部分，不计入模拟时间。

旧诊断场景没有 WASD、鼠标视角、碰撞或射击操作。通过页面链接可返回训练场。

## 修改旧诊断场景配置

入口：src/config/foundation.json。参数仅用于基础验证，不是正式关卡配置。

| 字段 | 含义 | 合法范围 |
| --- | --- | --- |
| schemaVersion | 配置格式版本 | 当前必须为 1 |
| worldSeed | 默认随机种子 | 1–128 字符，不能全为空白 |
| simulation.fixedHz | 固定模拟频率 | 整数 10–240，默认 60 |
| simulation.maxCatchUpSteps | 单帧追帧上限 | 整数 1–32，默认 8 |
| simulation.telemetryHz | 低频诊断更新频率 | 0.1 至 fixedHz，默认 2 |
| scene.size | 验证地面边长，米 | 8–200 |
| scene.markerCount | 灰色标记物数量 | 整数 0–300 |
| scene.probeSpeed | 绿色探针角速度，弧度/秒 | 0–4；0 表示静止 |

错别字、缺少字段、越界和未知版本会拒绝启动，并显示字段路径。不要通过删掉校验来让错误配置运行。生产构建包含配置，配置改变后需要重新构建。
