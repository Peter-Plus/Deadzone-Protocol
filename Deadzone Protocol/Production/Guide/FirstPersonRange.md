# 第一人称训练场使用

## 开始体验

双击项目根目录 Play.html，点击“开始 / 继续 · 锁定鼠标”。目标是击倒前方 5 个橙色靶子，默认每个靶子需要命中三发。

| 操作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D |
| 看向四周 | 鼠标移动 |
| 跳跃 | 空格；仅着地时可起跳 |
| 射击 | 鼠标左键或 F；按住连续射击 |
| 换弹 | R |
| 暂停 / 释放鼠标 | ESC |
| 重置靶子、弹药和成绩 | 暂停菜单“重新开始训练” |

如果浏览器不支持鼠标锁定，选择“窗口模式进入”：按住右键拖动，或用方向键观察；其余操作相同。画面适合桌面宽屏，没有触屏操作。

准星命中靶子会短暂显示叉号；命中点有短暂亮点，开火时枪口有闪光。靶子击倒后消失，右上角记录成绩。弹匣打空不会自动换弹；按 R。换弹动画的中后段才更新弹药，暂停会暂停动作。当前没有声音，也没有真实弹道散布/后坐力/瞄准镜。

切到后台或窗口失焦会暂停。返回后从菜单继续，不会自动继续开火。

## 这轮可以检查什么

1. 左右移动、转身、前后移动是否符合直觉。
2. 能否跳跃并落地，是否会穿过边界墙和掩体。
3. 对准橙色靶子射击是否命中；被高掩体挡住时是否不能打中。
4. 三发命中击倒后，弹药是否变为 27 / 180；换弹后是否为 30 / 177。
5. 按 ESC、切到后台、重新开始后，是否存在继续移动或自动开火。

制作人已完成本轮验收。上面清单供后续功能修改后的回归使用。自动化不能直接打开 file://，但游戏无需启动 npm 服务，也不应关闭浏览器安全设置。

## 调整测试数值

入口是 src/config/range.json。修改后由开发者执行 npm run check 或 npm run build，再重新打开 Play.html。不要直接修改生成 HTML。

| 配置 | 含义与注意事项 |
| --- | --- |
| fixedHz / maxCatchUpSteps | 默认 60Hz、每渲染帧最多追 8 步；严重卡顿丢弃超额墙钟时间。 |
| player.speed | 地面移动速度，默认 4.5 米/秒，范围 1–12。对角移动不会加速。 |
| player.jumpSpeed / gravity | 默认 6 与 18，影响跳高/落地时间；不表示耐力系统。 |
| player.height / radius / eyeHeight | 角色碰撞高度/半径/眼高。半径必须小于身高一半，眼高不能超过身高。 |
| player.sensitivity | 鼠标灵敏度，默认 0.002，越大转向越快。 |
| weapon.magazineSize / reserveAmmo | 弹匣容量和初始备弹；正整数容量与非负整数备弹。 |
| weapon.shotsPerSecond / damage / range | 每秒射击数、单发伤害、最大检测距离。当前仅支持自动 Hitscan。 |
| weapon.reloadCommit / reloadDuration | 当前资源对应 1.18 / 1.45 秒；提交点不能超过动作总长，随意修改会影响与动画同步。 |
| weapon.fireDuration | 当前 Fire 动画总长 0.26 秒；不是射速门控。 |
| targets | 靶子的 x/z 和 health。当前矩形场地支持 x=-11…11，z=12…32，数量 1–20；默认 5 个。 |

靶子位置是手工测试内容，不做自动避障/重叠校验，修改后要检查是否重叠或被掩体挡住。默认生效规则以校验器和实际源码为准。新增音效、敌人和正式武器系统应单独立项，不把测试场配置当最终全量玩法配置。
