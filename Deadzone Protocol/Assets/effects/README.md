# 特效资产

本目录存放场景与战斗特效，每款特效交付一个 `.vfx` 文件，素材和表现参数内嵌，统一使用 `ForgeVFX.mjs` 播放。制作侧的贴图、定义与脚本保留在 ForgeKit。已有 [命中溅血低强度样件](hit/README.md)，已通过制作人验收；[特效资产配置表](../特效资产配置表.md) 是统一登记入口，不是运行时自动加载配置。

## 分类与命名

使用契约见 [特效资产使用说明](../特效资产使用说明.md)。

以下子目录按实际交付需要创建，路径相对于 `Assets/effects/`，沿用现有美术工作项的分类。

| 子目录 | 用途 |
| --- | --- |
| `hit/` | 命中溅血等命中反馈 |
| `shadow/` | 影系技能、瞬移与透明变化 |
| `poison/` | 毒系投射物、护盾、毒爆与毒阵 |
| `fire/` | 火系投射物、光束、陨石与焰柱 |
| `chaos/` | 混沌技能与阶段变化 |
| `arena/` | 首领与 Boss 结界 |
| `status/` | 角色灼烧、毒伤的持续状态表现 |
| `equipment/` | 装备火／毒附魔反馈 |
| `world/airdrop/` | 信号枪空投落点标记 |
| `world/interactables/` | 附魔台封印、解锁、附魔与耗尽效果 |

资产 ID 与文件名使用小写英文和下划线，建议 `vfx_<类别>_<名称>[_<阶段或变体>]`。一个效果由多个文件组成时，使用同名子目录集中保存并逐项登记依赖。共用贴图只登记一份，由各效果明确引用。

## 交付约定

1. 正式源在 ForgeKit `definitions/effects/`；新增特效先写 `.effect.json`，校验、编译生成单个 `.vfx` 后同步至本目录。禁止将新的特效独立代码作为交付入口。
2. 当前通用图层为突发纹理粒子、局部空间柔雾／辉光、护罩／地面区域表面、可配置扇形尖刺与缠魂、几何环绕粒子和绑定模型的材质变化；新增能力扩展共用播放器，格式规范见 [ForgeKit 特效管线](../../../ForgeKit/rules/EFFECTS.md)。
3. 每款 `.vfx` 登记一个资产 ID／路径，记录播放方式、绑定、变体与验收状态。正式游戏接入单独记录。
4. 伤害、护盾、状态施加、附魔成功与奖励由 Gameplay 决定；状态转场仅改变表现。
5. 模型／动画 GLB 独立登记，UI 图标归入 ui。特效专用预览入口是 [ForgeKit/previewer/effects.html](../../../ForgeKit/previewer/effects.html)。
