# 低强度命中溅血

资产 ID：`vfx_hit_blood_low`。美术已于 2026-10-05 验收；已迁移为 [单文件 VFX](vfx_hit_blood_low.vfx)，正式游戏未接入。

每次 10 个暗红血滴，最长 0.46 秒，内嵌 128×128 RGBA 单帧贴图，UV 中心 (0.5, 0.5)，无碎片、积血或音效。源贴图、参数和制作脚本统一保存在 ForgeKit 正式 definitions/effects/hit 中，不再分散交付游戏。
