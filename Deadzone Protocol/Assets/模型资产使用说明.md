# FSA 模型资产使用说明

更新日期：2026-10-06。面向游戏项目的资源导入、装备挂接和动画接入。

## 1. 复制与导入

正式源库为 `ForgeKit/assets/FSA(项目使用)`；`ForgeKit/assets/legacy` 仅供测试与预览。模型或动画完成后，将正式库 generated 内的变更文件按相对路径同步到本目录，并同步维护资产配置表；生成与交付流程见 [AI 资产生成规则](../../ForgeKit/rules/ASSET_RULES_FOR_AI.md)。

将本目录的内容整体复制到游戏项目的资源目录，保留 `models/` 和 `animations/` 的相对目录结构。本说明中的路径都相对于复制后的资产根目录，与原磁盘位置无关。

当前目录包含 **59 个模型、88 段动画，共 147 个 GLB 文件**；具体名称和分组以资产配置表为准，包含本次大型交互物。

资产游戏内对应名称、实际文件路径及逐项备注统一记录在 [模型动画资产配置表](模型动画资产配置表.md)。本说明维护导入、挂接和动画使用契约。

```text
资产根目录/
  模型资产使用说明.md
  模型动画资产配置表.md
  models/
    weapons/<类型>/<类型_编号_名字>/
    fps_arms/
    characters/enemies/
      common/             A1～A4
      elite/              B1～B3
      bosses/             C1～C3、D1
    characters/npcs/
  animations/
    fps/unarmed/
    fps/firearm/shared/
    fps/melee/shared/
    fps/throwable/shared/
    characters/shared/
    characters/overrides/bosses/phantom/  C1 专用动画
    characters/overrides/bosses/plague_beast/  C2 专用动画
```

- 格式为 GLB（glTF 2.0）；模型内含几何和材质，无需另行寻找贴图文件。
- 资产使用米制，+Y 向上、+Z 为模型正前方。若引擎坐标系或单位不同，统一转换模型、动画和插槽，避免分别旋转或缩放造成错位。
- 保留节点名称、层级和局部变换；不要在导入时合并掉动画节点或插槽。不要自动重置模型姿态或把模型中心重新设为原点。
- `.anim.glb` 是独立动画资源，每个文件有一段动画。提取动画并绑定到目标模型的同名节点；场景里显示模型实例，不需要另行显示动画文件的节点树。
- 每个活动角色或双臂对象应拥有独立的动画状态和可变节点实例，避免多个角色互相影响。

## 2. 模型与配置表

模型逐项名称与路径见 [模型动画资产配置表](模型动画资产配置表.md#模型)。武器是独立静态模型，原点为主握装配点，使用默认缩放 1；各类型编号独立，使用完整资产 ID 或配置表路径区分。

完整角色包含 A1 疫鬼、A2 持斧疫鬼、A3 影·疫鬼、A4 炎·疫鬼、B1 追猎者、B2 爆裂斧手、B3 毒箭手、C1 魅影、C2 瘴疫兽、C3 炎巫、D1 混沌及商人罗德。角色以双脚中心地面为放置基准。FPS 双臂不以脚底或人物身高定位。

A2、B2 的斧头、A4 的法杖、B3 的弓和预装箭均已内置，不要重复挂载。A4 骨架高度为 1.62 米，B2 为 2.34 米；动画绑定须保留各模型自身的骨骼平移基准。

### C1 魅影：双刃与实例材质

C1 为纤细的变异女性，现使用 **humanoid.v2 十三节点**。2026-10-05 改为圆润的头脸、腰胯、胸臀及分段四肢，非武器部件无 box 几何；保留冷灰肤色、不对称长发和紫灰异变。parameters.height=1.8，Asset 根节点已含 scale=1.1，默认脚底 y=0、头顶 y=1.98 米；导入后不要再乘 1.1。保留原七节点局部平移，Body 局部基准仍为 0.828 米。头发、异变外壳及手指为固定外观，无独立骨骼。

新增关节局部坐标（均在根缩放之前）：Forearm_L/R 相对 Arm 为 `[±0.27,0,0]`；Hand_L/R 相对 Forearm 为 `[±0.217,0,0]`；LowerLeg_L/R 相对 Leg 为 `[0,-0.39,0]`。前臂及护腕挂 Forearm，手掌、手指与刀柄挂 Hand，膝部、小腿、靴子和鞋底挂 LowerLeg。

- 两把反握利刃已内置，分别挂在 `BladeGrip_L` / `BladeGrip_R` 下；插槽父节点为 `Hand_L` / `Hand_R`，原点在对应手掌内，不重复挂装备。
- 握点局部位置为 `[±0.048, 0.006, 0.026]`（未乘根缩放），局部 Z 旋转左 -90°、右 +90°。握点的局部 +Y 沿刀身指向刀尖。`BladeTip_L` / `BladeTip_R` 挂在对应握点，局部位置 `[0, 0.475, 0]`，仅提供刀尖参考；不含命中事件或伤害判定。
- 所有材质默认不透明（opacity=1）。本体和分身可以复用几何，但创建每个实例时必须复制其全部可变材质，包括皮肤、衣物、头发、眼睛与双刃；Three.js 的 Object3D.clone 本身不会复制材质，需要逐个 Mesh 克隆 material，数组材质也逐项处理。修改实例内所有材质，避免隐身时留下眼睛或武器。
- 淡隐时设置 transparent=true、opacity 为目标不透明度，可关闭 depthWrite；完全隐藏时隐藏整个实例。恢复时还原原始 opacity、transparent 和 depthWrite，材质透明模式切换时更新 needsUpdate。多层几何的常规透明混合会出现内部表面叠加，若最终玩法需要均匀轮廓消隐，须在表现层另行实现整体淡出/抖动方案。
- 八段专用动画已升级为原生 humanoid.v2，显式驱动全部十三节点，含独立屈肘、转腕、屈膝；命中事件不变，AmbushStrike 因追加斩后缓冲延长至 1.42 秒，其余时长保留。共用 Walk 仍为 v1，须通过 ForgeRuntime.compatibility / prepareClip 显式 v1→v2 适配。所有片段加载时 captureRestPose，停止时 stopAllAction / uncacheRoot 后 restoreRestPose。C1 现已交付专用 Idle、Attack、Run、Hit、Death、ShadowDart、Vanish、AmbushStrike。Walk 可复用角色共用动作；魅影突袭和分身出现后的蓄势与斩击使用单段 AmbushStrike，不再拆为 Charge + Attack。
- 本体与分身保持相同外观。实例材质隔离验证仅在资产预览完成；受击渐隐、瞬移、分身、血条与溅血反馈仍需运行时接入。

Attack_L 的局部 Z 旋转仍为 -90°，其余插槽旋转为零。Cast_L +Z 是参考姿态下的掌前方，Attack_L +Y 沿手臂向爪尖；轴会随手腕变化。投射方向、吸引扇区、命中体积和事件时刻仍由 Gameplay 单独配置。

旧 humanoid.v1 动画须使用 ForgeRuntime.compatibility(modelMeta, animationMeta) / prepareClip 的显式 v1→v2 单向适配，不能跳过签名校验或要求三字段完全相等。加载时立即 captureRestPose；停止时先 stopAllAction / uncacheRoot，再 restoreRestPose。prepareClip 保留 Body 的 1.55 米平移基准，并补齐新增关节的默认旋转。十三节点迁移阶段已验证十段旧共用动作的单向适配。本轮外观修订后，对 Idle/Walk 各取 49 个时点检查左手与躯干/腿部间隙，并保留巨斧握点和右侧几何不变。左手默认下垂、Idle、Walk、关节演示的最小侧向包围盒间隙分别约 0.237、0.237、0.144、0.134 米；Idle/Walk 中整只左手最低离地约 0.447 米。检查范围不等于保证任意手工姿态或所有战斗动作均无穿插。这不代表全部动作适合混沌战斗，现已交付十三段专用动作，详见后文；移动、魔化和其余技能动作仍待制作。

审阅页提供屈肘/转腕/屈膝演示及右肘、右腕、左膝滑条，仅供模型检查，不是正式动画。魔化应统一缩放角色外层实例（如 1.3 倍），包含骨架、斧头和全部插槽；外部特效读取节点世界变换，Gameplay 碰撞与范围另行配置。

每个 Boss 实例复制全部可变节点与材质（含眼睛、爪尖、斧头），几何可共享。Object3D.clone 不会自动复制材质，需遍历 Mesh 克隆 material，数组逐项处理。隐身时隐藏整个实例；淡隐设置 transparent / opacity，可关闭 depthWrite，恢复时还原参数并按需更新 needsUpdate。实例材质隔离与 1.3 倍整体缩放已在实际 GLB 预览验证；游戏中隐身、吞噬、魔化和技能行为仍待接入。骨架契约见 [humanoid.v2](../../ForgeKit/rules/HUMANOID_V2.md)。

## 3. FPS 装备与相机

### 装备挂接

在双臂实例中递归查找以下节点，名称区分大小写：

| 节点名 | 用途 |
| --- | --- |
| `Weapon_R` | 原单武器挂接点：七种枪、军用匕首、手雷均使用此点；暗影双刃使用专用握点 |
| `Weapon_L` | 原左手支撑参考点，无需挂装备 |
| `ShadowBlade_L` / `ShadowBlade_R` | 暗影双刃专用左／右握点，分别挂对应独立刃模型 |
| `Camera_FPS` | 第一人称相机的位置与朝向参考 |

挂接武器时，将完整武器实例设为 `Weapon_R` 的子对象，并将武器实例局部位置和旋转清零、缩放设为 1。保留武器内部节点变换，不要额外补偿握把位置。若引擎已作统一单位转换，沿用对应的统一尺度。

持枪位置位于画面右侧，左手位于右手前方、略低处。左手是共用持枪动画的视觉辅助，不需要把同一把枪再约束到 `Weapon_L`。七类枪目前共用 Firearm 动画；军用匕首使用 Melee，手雷使用 Throwable，空手使用 Unarmed；暗影双刃使用专用 ShadowBlades 动画。

弹匣、枪机等是静态外观。Reload 和 Bolt 表现为手臂动作，不包含独立弹匣拆卸或枪机活动。

### 暗影双刃：专用双持与动画（2026-10-05）

暗影双刃是一件近战装备，由两个独立静态 GLB 组成。各自原点为握柄中心，局部 +Y 从柄指向刃尖，±Z 为刀身正反面；两面均有暗紫纹饰，刃尖略朝各自外侧偏斜。米制，默认缩放 1，不使用负缩放镜像；模型与八段动画的准确路径见配置表。左右刃含 GripOrigin、Blade_Base、Blade_Tip 参考节点，查找时以各自武器实例为根，避免左右同名节点混淆。

现有双臂模型新增两个非骨骼 Socket：

| Socket | 父节点 | 局部位置 | 局部 Euler XYZ（度） |
| --- | --- | --- | --- |
| ShadowBlade_L | Forearm_L | [0,0,0.251] | [40,16,-12] |
| ShadowBlade_R | Forearm_R | [0,0,0.251] | [40,-16,12] |

分别将左刃、右刃完整实例挂到对应 Socket，实例局部位置/旋转清零、缩放 1。不要挂 Weapon_L，不要将两刃都挂 Weapon_R。专用 Socket 位置对齐现有 Glove 中心；握持外倾已包含在 Socket 旋转中，不再额外补角。切换装备时同时卸下两刃；卸下实例而非删除 Socket，防止重复挂载。原 Weapon_L、Weapon_R、Camera_FPS 的变换、双臂几何和 fps-arms.v1 签名保持不变。

八段动画均绑定同一个双臂实例，不对静态刃模型分别播放手臂动画。使用当前 fps-arms.v1 的四关节单轴旋转，表现为前伸斜刺与下切，不含额外手腕、横向挥肩或 Root Motion。专用持握姿态四关节 X 增量依次为 UpperArm_L=22°、Forearm_L=-26°、UpperArm_R=26°、Forearm_R=-30°；左肩 stance 偏移 [+0.15,0,0]。默认左右握点横向间距约 0.358 米，已按反馈由约 0.296 米加宽，三段循环和攻击收招均使用相同边界姿态。

| 动作 | 原始时长 | 循环 / 事件 |
| --- | --- | --- |
| Idle | 2.40 秒 | 循环；轻微呼吸 |
| Walk | 0.90 秒 | 循环；交替摆动 |
| Run | 0.62 秒 | 循环；加大交替摆幅 |
| Draw | 0.30 秒 | 单次；技能不可用时的普通切出 |
| Holster | 0.30 秒 | 单次；末帧卸下两刃 |
| Attack1（策划 attack1） | 0.64 秒 | 单次左刃攻击；0.29 秒命中参考，建议窗口 [0.23,0.34] |
| Attack2（策划 attack2） | 0.64 秒 | 单次右刃攻击；0.29 秒命中参考，建议窗口 [0.23,0.34] |
| ShadowDash（影袭） | 0.76 秒 | 单次；0–0.14 秒前摇，0.14–0.38 秒位移/命中，0.38–0.76 秒恢复 |

**持续普攻：** Attack1 → Attack2 → Attack1 → Attack2；两段保持 loop=false，由装备状态机交替启动。两段首尾均与 Idle 首帧完全匹配，停止输入后完成当前恢复段再回 Idle/Walk/Run，不继续排队下一击。仅活动侧 Blade_Base/Blade_Tip 参与本次扫掠，配合侧没有伤害事件；每段每目标去重一次。伤害和实际判定半径由 Combat 配置，不能把约 0.79 米的刃尖前伸范围直接当武器射程。

**切出与影袭：** 原先持有其他武器时，先完整播放旧类别 Holster 并卸下旧模型，再挂两刃。影袭满足 Gameplay 条件时直接启动 ShadowDash，不先播放 Draw；空手切出时直接挂两刃并启动 ShadowDash。由空手或旧 Holster 进入时，在影袭前 0.06 秒内从上一姿态短混合四关节与左肩位置；该过渡包含在 0.14 秒前摇内。旧 Holster 与影袭首帧的四关节旋转一致，但左肩从标准 X=0.15 米过渡到双持 X=0.30 米，不能直接跳变。普通 Draw 使用 stance.in，最后 25% 淡入左肩偏移；Holster 使用 stance.out，开始 25% 恢复标准左肩。其余专用动画（包括 ShadowDash）使用 stance.constant。

技能不可用（例如冷却/耐力/可用路径条件不满足）时，旧武器收起完成后改走 Draw → Idle，不播放影袭的攻击段。空手到 Draw 的前 0.06 秒也从当前姿态短混合。当前枪械 Holster 为 0.42 秒、军用匕首/投掷物为 0.34 秒，额外计入切换前摇，不压进 ShadowDash 或 Draw 时长。约 12 秒冷却、耐力消耗、1.15 倍翻滚距离仍使用 Gameplay 配置；本动画不自行扣费或判断路径。

**影袭事件：** 本地 0.14 秒结束前摇，Gameplay 开始沿锁定前向的碰撞受限位移；0.14–0.38 秒仅对合法移动路径上的目标做近战命中/扫掠，并在整次影袭内去重，两把刃不能让同一目标自动重复受伤。0.24 秒为双刃前伸峰值，可用作命中特效参考；不是额外伤害事件。0.38 秒结束攻击窗口，0.76 秒回持握。中途被墙阻挡时立即停止位移/扫掠，按状态规则恢复，不能为赶上动画而穿墙或补足剩余距离。死亡或有效中断取消未提交事件；技能只在切出时尝试，普通 Attack1/2 不触发影袭。

**收起与翻滚：** Holster 0.30 秒结束后同时卸下左右刃，再播放既有 Unarmed Roll 0.80 秒；收起是非空手翻滚前摇，合计 1.10 秒。Roll 起始短混合到空手姿态，结束保持空手，不自动 Draw 或影袭。切换回单武器/空手时恢复左肩标准位置，避免残留双持偏移。

**验证与范围：** 八段实际 GLB 共 797 个时点检查：Root 固定、合法轨道/签名、握点稳定、循环与攻击边界、双刃之间及刀身与手臂的有向包围盒穿插通过；刃模型距相机前平面的最小深度约 0.125 米。已检查 16:9、70° 垂直 FOV 第一人称及侧面/模型视图，左右交替连击、三类旧装备收起后接影袭或普通 Draw、空手入口及收双刃接 Roll 的预览。检查是当前资产和所述混合方式的验证，不代表游戏状态机已接入。已同步正式资产；掉落、双持装备逻辑、伤害、位移、耐力、冷却、技能粒子/音效尚未实现。

### 相机接入约定

`Camera_FPS` 是定位节点，不是已经配置好的相机对象。相机采用局部 **-Z** 为前向时，可以在该节点下挂相机并清零相机局部位置、旋转；此时视线朝资产 +Z。若引擎相机采用 +Z 为前向，应转换相机朝向约定，不能直接照搬 -Z 相机的旋转。

初始画面建议使用垂直视野角 **70°**、近裁剪面 **0.005 米**；这是调试构图的起始值，可按项目调整。相机点位已包含后退、抬高的构图偏移。

由玩家视角控制器驱动整个第一人称视图组，再使用该组内的相机点位。若项目已有主相机，可让相机与双臂保持同样的相对关系；选择一种驱动方向，避免相机跟随双臂、双臂又反向跟随相机的循环依赖。相机不应跟随手臂关节的挥动。

双臂通常只对所属玩家的第一人称视图显示；世界中的其他角色使用完整人物模型。

## 4. 动画绑定与播放原则

FPS 与完整角色是两套独立骨骼，动画不能交叉使用：

| 对象 | 动画目录 | 动画绑定节点 |
| --- | --- | --- |
| FPS 双臂 | `animations/fps/` | `UpperArm_L`、`Forearm_L`、`UpperArm_R`、`Forearm_R` |
| A1～A4、B1～B3、罗德 | `animations/characters/shared/` | `Root`、`Body`、`Head`、`Arm_L`、`Arm_R`、`Leg_L`、`Leg_R` |
| C1 魅影 | 八段原生 v2 专用动作；共用 Walk 须显式 v1→v2 适配 | 原七节点 + `Forearm_L/R`、`Hand_L/R`、`LowerLeg_L/R`，共十三节点 |
| C2 瘴疫兽、C3 炎巫、D1 混沌 | 旧共用动画须显式 v1→v2 适配；C2 有十四段、C3 有六段专用 v2 动作，D1 有十三段专用 v2 动作 | 原七节点 + `Forearm_L/R`、`Hand_L/R`、`LowerLeg_L/R`，共十三节点 |

这些资产适合按原节点层级播放动画，不需要套用引擎标准完整人形骨架。v1 完整角色没有独立肘、膝、腕；C1/C2/C3/D1 的 v2 骨架包含这些关节，所有完整角色均没有独立手指节点。导入时选择能保留原节点动画的模式，不要自动强制映射成另一种人体骨架。

- GLB 中的动画为局部变换动画，按普通覆盖动画播放；不要把它们直接作为叠加姿态再加到当前旋转上。
- 保留旋转和位移曲线。FPS 持枪动画含左臂摆位曲线，角色动画也含身体位移；只导入旋转会丢失效果。
- 骨骼名称匹配之外，应检查 rigId、rigVersion、rigSignature。不同体型的角色需将动画的 canonical-local 平移按“关键帧值 − 动画 canonicalTranslations + 目标模型对应节点原始位置”重定基准，避免 A4、B2、C2、C3、D1 播放动画后被拉回 1.8 米体型的骨骼位置；旋转仍按同名节点绑定。
- 从 Firearm 切换至空手、近战或投掷时，让不再受新动画驱动的节点属性恢复模型原始值，尤其是左肩局部位置，避免残留持枪偏移。过渡期间可由动画混合系统平滑恢复，不要重置仍在播放的动作。
- Idle、Walk、Run 和角色共用 Charge 循环；其余动作单次播放。动作切换可采用短暂交叉淡化。Death 播放结束后保持末帧，不返回站立。
- 全部动画都是原地动作。移动速度、朝向、碰撞和导航由游戏驱动角色外层对象；不要将动画节点的局部变换当成角色控制器的世界移动。
- 完整角色无动画时是 T 形参考姿态。角色生成后应进入 Idle；FPS 装备就绪后也应进入对应类别的 Idle，而不是停留在模型默认姿态。

### 玩家翻滚（2026-10-05）

仅保留 Unarmed Roll：0.80 秒、非循环、fps-arms.v1，四个合法单轴旋转关节。已删除持枪 Roll 的源定义及正式库、游戏 Assets 中的 GLB。Root、相机和玩家世界位置不随片段移动。

**播放顺序：** 空手直接播放 Roll；非空手先完整播放当前装备对应的 Holster（收枪、收刀或收投掷物），该段作为翻滚前摇，完成后卸下手持可视模型、将手持状态转为空手，再开始同一段 Unarmed Roll。不丢弃背包物品、不生成投射物。Roll 中没有 0.14 秒隐藏武器事件。

按现有动画 1× 速度，枪械前摇 0.42 秒，总长 1.22 秒；刀与投掷物前摇 0.34 秒，总长 1.14 秒；空手总长 0.80 秒。不得把 Holster 压进 Roll 的 0.80 秒，也不与 Roll 并行播放。翻滚位移阶段从 Roll 开始计时；耐力、冷却、输入锁定和中断规则由 Gameplay 接入。

Roll 首尾均精确对齐 Unarmed Idle 首帧：UpperArm_L/R 的局部 X 增量为 25°，Forearm_L/R 为 -55°，左肩为 [0.15,-0.16,0]。Holster 末帧不同，需在完整 Holster 结束后，于 Roll 起始约 0.04–0.06 秒内从其末姿态短混合，并恢复左肩标准位置；混合包含在 Roll 的 0.80 秒内。由空手 Walk/Run 进入也可如此短混合。

动作本身保持不变：0–0.14 秒收臂；0.14–0.36 秒抬前臂护身；0.36–0.51 秒收紧并下压；0.51–0.64 秒落稳缓冲；0.64–0.76 秒恢复空手，0.76–0.80 秒保持末姿态。使用 LoopOnce、clampWhenFinished，结束后衔接空手 Idle/Walk/Run，禁止自动 Draw，玩家手动切装备时才拿出。

Holster 完成事件每次仅提交一次；前摇或 Roll 中断、死亡时取消未执行的后续动作及事件，不让旧回调自动启动 Roll 或重新显示武器。GLB 不包含 Gameplay 事件。本次仅调整资产与接入契约，游戏的收起前摇、翻滚位移、相机及装备状态逻辑仍待接入；保留无无敌帧规则。

### 推荐状态衔接

- 普通持枪：Idle / Walk / Run → Fire → 返回当前移动状态。连发射速由武器配置决定，0.26 秒的视觉动作时长不等同于强制射击间隔。
- 本项目 DMR、SR：Fire → Bolt → 返回当前移动状态；下一次开火需等待项目的拉栓状态允许。
- 换弹：进入 Reload，在弹药提交点更新弹药，动作结束后返回当前移动状态。
- 换装备：旧类别 Holster 完成 → 移除旧武器 → 新武器挂 `Weapon_R` → 新类别 Draw → 新类别 Idle / Walk / Run。不要在 Holster 与 Draw 之间重置双臂为默认姿态。
- 切为空手：旧类别 Holster 完成 → 移除武器 → 淡入 Unarmed。空手没有 Draw/Holster，空手切入装备时挂载新武器并衔接对应 Draw。
- 投掷：Throw 到释放点时移除手中物体并生成世界投射物；有剩余物品时由游戏决定何时补充并播放 Draw，否则转入空手或其他装备。

### FPS 动画事件约定

以下时刻均以 **1 倍速、当前动作开始后经过的秒数**计算，供游戏配置事件使用；GLB 不会自动执行这些玩法操作。改变播放速度时按动画本地时间触发，而不是使用固定现实时间延迟。

| 动作 | 时刻（秒） | 游戏处理 |
| --- | ---: | --- |
| Firearm / Fire | 0.00 | 开火判定、消耗弹药、射线或投射物、音效和枪口效果 |
| Firearm / Reload | 1.18 | 提交换弹结果，一次性更新弹药 |
| Firearm / Bolt | 0.40 | 上膛就绪标记；完整动作在 0.62 秒结束 |
| Melee / Attack | 0.28～0.43 | 开启并关闭近战命中窗口 |
| Throwable / Throw | 0.38 | 隐藏或移除手持手雷，按 Weapon_R 当前世界位置生成投射物并赋予投掷速度 |
| 任意装备 / Holster | 动作末尾 | 卸下旧装备，进入切换阶段 |
| 任意装备 / Draw | 0.00 | 确认新装备已挂载 |

每次播放每个事件只触发一次；时间跨过事件点时也要触发，不能要求浮点时间恰好相等。动作中断、重复输入、弹药不足和死亡时，由游戏明确取消或保留已经提交的操作。近战命中窗口内建议对同一目标去重。

**原地动画与示意高度分开。** GLB 不含 Root Motion，也未将米级跳跃写进 Body。审阅页提供可关闭的“示意跳跃位移”，在模型容器上叠加以下 Y 高度以检查先落拳、后落脚。正式接入需由 Gameplay 驱动同样或经过校准的轨迹；只播原地 GLB 不会自动跳起。横向跳向玩家的位移、地形适配和命中范围不在审阅轨迹中。

- 定义 S(x)=u²(3−2u)，u=clamp(x,0,1)。所有高度单位为米，时间是片段本地秒。
- 普通/高跃起：D=0.65/0.95，H=1.20/1.80；前 0.12 秒 Y=0，其后 u=clamp((t−0.12)/(D−0.12),0,1)，Y=H×[1−(1−u)³]。
- 砸击 1/2：D=0.80、H=1.20、h=0.31600793；砸击 3：D=1.40、H=1.80、h=0.58565155。前 0.10 秒 Y=H+(h−H)×S(t/0.10)；随后 u=(t−0.10)/(D−0.10)，Y=h×[1−S((u−0.56)/0.44)]。
- 上述公式与审阅页内嵌采样表一致；模型缩放时示意高度也须同倍缩放。若改跳高、落地时间或角色尺寸，应重新核对拳地接触，不能只沿用事件时刻假定接地。

审阅页支持单段循环、0.25×/0.5×/1×速度、拖动时间、旋转视角，以及完整三连的循环播放。循环是预览选项，六段正式技能 GLB 的 loop 均为 false。Hit、Death 已追加交付，首领玩法仍待接入。
