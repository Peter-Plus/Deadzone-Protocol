# 项目资产目录

本目录存放 Deadzone Protocol 的交付资产。配置表中的文件路径均相对于本目录；资产入库与游戏运行时接入分别记录。

## 目录分类

| 目录 | 用途 | 当前状态 |
| --- | --- | --- |
| `models/` | 角色、武器、场景物件等三维模型 | 已有资产 |
| `models/projectiles/` | 五种飞行物实体与特效定位槽 | 已入库并通过美术验收，待运行时接入 |
| `animations/` | 角色与第一人称双臂等动画 | 已有资产 |
| `ui/` | UI 图标及后续界面美术资产 | 已建立，待制作 |
| `ui/icons/` | HUD、物品、装备、元素等 UI 图标 | 已建立，待制作 |
| `2d/` | 非 UI 用途的二维插画、精灵、贴图等 | 预留分类，尚未创建 |
| `effects/` | 场景与战斗特效、粒子贴图及序列图 | 已有资源；命中溅血已验收，见[配置表](特效资产配置表.md) |

按用途归档：用于界面的二维图片归入 `ui/`；用于特效的二维贴图归入 `effects/`。`2d/` 在首次交付时建立目录及对应配置表。
