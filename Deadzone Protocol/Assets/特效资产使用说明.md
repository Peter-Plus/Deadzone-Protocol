# 特效资产使用说明

当前特效采用 ForgeKit `forge-vfx.v1` 单文件格式。每款特效只需配置一个 `.vfx` 路径，贴图与表现参数已内嵌；全部特效共用 `effects/ForgeVFX.mjs`。实际路径与美术状态统一见 [特效资产配置表](特效资产配置表.md)。两款已验收美术已迁移，正式游戏玩法仍未接入。

## 加载与生命周期

Three.js 由项目提供，共用播放器不再重复打包 Three.js。构建时用 `.vfx: text` 加载器内嵌资产，不在 file:// 页面 fetch 磁盘路径。产物仍需保持自包含 Play.html。

```js
import { createEffect } from './effects/ForgeVFX.mjs';
import bloodText from './effects/hit/vfx_hit_blood_low.vfx';

const blood = await createEffect(bloodText, { scene });
// 同一个播放器可承载多个命中；由 Combat/Character 确认允许后提交。
blood.emit({ position: [x,y,z], normal: [nx,ny,nz], seed: hitId, allowed: true });
blood.update(deltaSeconds);
// 中断／关卡重置
blood.clear();
blood.setState('impact'); // 重置时间并恢复可播放
// 场景销毁
blood.dispose();
```

- `emit` 默认不允许播放，只有 `allowed === true` 才发射；高防护盾、魅影分身由玩法排除，不能按模型名称猜测。
- 血滴位置、向外法线为世界空间，米制；粒子出生后不跟随敌人。共用播放器的世界坐标突发图层不受参考模型缩放影响。
- `update(dt)` 推进表现时间，暂停时不推进；`seek(seconds)` 从最近一次 setState 的起点确定性采样，可前后拖动。`setState(state,variant)` 重置该实例及其粒子；多个事件连续发生时只调用 emit，不要每次先 setState。
- `clear()` 清掉粒子、隐藏效果并恢复被修改材质；后续 update 不继续推进。`show()` 恢复当前表现，或 setState 重建明确状态。
- `dispose()` 释放播放器拥有的纹理、图层几何与材质，并恢复模型原材质引用；不会释放宿主的模型几何或动画。不同模型实例分别创建效果控制器；同一个模型不应同时被多个材质控制器改写同一节点。
- 血滴固定批次容量 64 组，每组 10 粒子，超出覆盖最早组；这是显示预算，不影响伤害结算或敌人数量。

## 附魔台绑定与动画同步

`vfx_altar_feedback.vfx` 引用模型 `FSA_WORLD_EnchantAltar`、动画 `FSA_ANIM_EnchantAltar_Enchant`，挂在 `Asset` 根。模型与动画 GLB 独立加载，不内嵌进特效。实际路径见模型动画配置表。

```js
const feedback = await createEffect(altarText, { scene, model: altarModel });
feedback.setState('sealed', 'fire');    // 或 poison
feedback.setState('unlocking', 'fire'); // 保留封印元素，0.65 秒后表现为 unlocked
feedback.setState('enchanting', 'poison'); // 已确认附魔结果后播放，2.4 秒后表现为 exhausted
feedback.setState('exhausted', 'poison'); // 读档时可直接恢复
```

| 玩法提供的状态 | 表现状态／变体 |
| --- | --- |
| 普通可用／解锁可用 | `available`／`unlocked` |
| 火封印／毒封印 | `sealed` + `fire`／`poison` |
| 封印解除 | `unlocking` + 原封印元素 |
| 火／毒附魔过程 | `enchanting` + 对应元素 |
| 使用耗尽 | `exhausted` |

播放器只改变粒子和材质，节点动画由宿主按照文件 `binding.animationStates` 同步：`time` 使用当前表现秒数、`end` 取片段末帧、未配置或 `rest` 恢复参考姿态。附魔台当前 enchanting=time、exhausted=end。每实例独立 Mixer；签名验证和片段准备使用共用 [ForgeRuntime.js](runtime/ForgeRuntime.js) 的 metadata／prepareClip／captureRestPose／restoreRestPose。独立预览器的 `syncModel` 提供可运行参考。

`next` 只决定视觉末态，不能自行把设施设为已使用、消耗晶核或产生奖励。玩法中断或存档恢复时，调用方必须用真实状态覆写表现。Placement 不是特效内容，已归到 [设施摆放参考](models/world/interactables/Placement.json)。

## 魅影紫气、蓄力紫光与隐身雾气

三项均为自包含 `.vfx`，仅预览特效本身，没有内置模型绑定。按约 1.98 米高的魅影设计，坐标为米制、+Y 向上，原点在效果中心。正式玩法尚未接入。

| 文件（位于 effects/shadow/） | 状态／时长 | 触发与挂点 |
| --- | --- | --- |
| `vfx_shadow_phantom_arrival.vfx` | arrival／1.10 秒 | 瞬移确认到达后播放；身体中心跟随角色，建议世界脚底位置 + (0, 0.99, 0) |
| `vfx_shadow_phantom_charge.vfx` | charge／0.70 秒 | AmbushStrike 二段蓄力开始时播放；左右 Hand_L／Hand_R 各一个实例，或各自手心 BladeGrip_L／R 挂点 |
| `vfx_shadow_phantom_vanish.vfx` | vanish／0.95 秒 | 前段 Vanish 开始时展开，包裹身体后淡出；留在消失位置，不跟着隐身后的瞬移移动 |

宿主可建立单位缩放的 Three.Group，将其世界位置同步到身体／手心，再通过 `createEffect(text, {scene: followGroup})` 创建局部效果。魅影 Asset 已含 1.1 倍缩放；直接挂在其子节点时应补偿继承缩放，避免再次放大。双手使用同一份 charge 文件创建两个独立实例，不需要两份资产。

cloud 图层创建即按初始状态显示，随每帧 `update(dt)` 推进，不需要 emit。重复播放用 `setState('arrival')`、`setState('charge')` 或 `setState('vanish')`；到时进入 finished 并隐藏。`emit({position,allowed:true})` 对 cloud 仅重定位当前实例，position 为父级局部偏移，不生成多个云团，也不重置播放时间；多个角色分别创建实例。

二段紫光覆盖 AmbushStrike 开始至约 0.70 秒攻击点，实际伤害仍由 Gameplay 事件提交；Vanish 动画约 0.52 秒、隐身持续 1～3 秒也不由雾气的 0.95 秒寿命控制。蓄力被打断、角色死亡或脱离场景时调用 clear，销毁时 dispose；不得因视觉播完而补发攻击。薄紫气与包身雾气只改变显示，不代替角色材质透明度规则。

## 瘴疫兽毒盾与毒阵

三项位于 `effects/poison/`，无外部贴图。正式游戏未接入；可在 [临时组合审阅页](../../ForgeKit/.qa/poison-effects.html) 检查模型包裹、直线位移和半径缩放。

### 毒素护盾

`vfx_poison_toxic_shield.vfx` 以角色脚底为原点、+Z 朝前、单位缩放，跟随角色世界位置和朝向。瘴疫兽模型已带 2.2 倍根缩放，不要再给特效乘 2.2。建议挂在模型外的单位缩放跟随组。

护罩局部中心为 `(0, 2.0498, 0.6860)`，三轴半径为 `(4.0660, 2.6199, 3.0465)` 米。根据实际 5 秒 ToxicShield 动作确定，301 个时点检查模型顶点均在椭球内；包含前伸巨拳。其范围是包身视觉尺寸，不作为爆破伤害半径。

| 真实事件 | 表现调用 | 视觉结果 |
| --- | --- | --- |
| 护盾成功获得 | `setState('active')` | 持续护罩，不自动在 5 秒后消失 |
| 有效受击，护盾尚存 | `setState('hit')` | 0.22 秒闪烁后回 active |
| 护盾破裂／蓄力中断 | `setState('broken')` | 0.48 秒散去后 finished |
| 蓄力成功结束 | `setState('release')` | 0.65 秒扩张收束后 finished |

破盾后取消爆破和毒阵由 Gameplay 执行；release 不自动造成伤害、不自动生成毒阵，也不是独立毒爆资产。死亡、场景切换可直接 clear，实例销毁时 dispose。

### 矩形毒阵：传端点即可增长

`vfx_poison_field_rectangle.vfx` 的基础宽长为 1×1 米，位于 XZ 平面，中心原点、+Z 长轴，表面抬高 0.025 米防止闪面。腐烂冲撞是锁定方向的直线，采用一个矩形实例沿实际位移增长，避免额外分段拼接。

```js
const trail = await createEffect(rectangleText, { scene });
// startGround：冲撞开始的地面位置；currentGround：当前实际地面位置。
// 首帧起终点相同，宽度为配置值，此时没有可见长度。
trail.setSegment(startGround, startGround, widthMeters);
// 位移期间逐帧更新；无需每帧 setState，也无需自行算角度和缩放。
trail.setSegment(startGround, currentGround, widthMeters);
trail.update(dt);
// 冲撞结束：停止更新端点，已形成的毒阵仍保留，并继续 update。
// Gameplay 确认毒阵到期后：
trail.setState('fading'); // 0.80 秒到 finished；或 clear() 立即隐藏
// 不再使用时 trail.dispose();
```

`setSegment(start,end,width)` 返回实际长度，自动设中心、朝向和 XZ 缩放。坐标为父级局部空间，通常直接传入未变换 scene，此时就是世界坐标；端点为有限三维数组、同一地面高度，宽度须大于零。仅适用于居中的单位矩形 surface 图层。零位移长度为零；停止更新不会自行消失，也不采样未来路径。重用实例时重新设置起点和终点。

这是**平地直线矩形**，不记录弯曲轨迹，不进行地形贴合或碰撞查询。每次冲撞独立创建／复用一个实例；端点、宽度、持续时间必须和 Gameplay 的实际毒阵范围相同。材质细节按世界坐标采样，拉长时气泡不会被拉成条纹。

### 圆形毒阵：一个单位半径资产

```js
const field = await createEffect(circleText, { scene });
field.root.position.set(x, groundY, z);
field.root.scale.set(radiusMeters, 1, radiusMeters); // 基础半径 1 米
field.update(dt);
// 真正到期后 field.setState('fading')，立即移除则 field.clear()。
```

`vfx_poison_field_circle.vfx` 边界为半径 1 米圆，XZ 均设为配置半径，Y 保持 1。圆心位于地面中心，视觉表面额外抬高 0.025 米。边缘淡化在范围内侧，不向范围外扩散。active 无固定毒阵寿命，fading 为 0.80 秒纯视觉淡出；雨天的期限和附毒量由 Gameplay 控制，不能根据特效时钟施加毒伤。

## 通用火球与追魂魔种

`effects/fire/vfx_fire_fireball.vfx` 供炎·疫鬼和炎巫普攻共用；`effects/chaos/vfx_chaos_soul_seed.vfx` 为追魂魔种。均为纯特效，贴图内嵌，不加载模型。原点在火核／魔核中心，米制、+Y 上、+Z 前，可等比缩放。

火球亮核及火舌主体直径约 0.7 米，短焰尾向 -Z 延伸，含软边总长约 1.5 米；魔种黑雾软边直径约 1 米。这些是视觉参考，不是碰撞尺寸。火球尾焰随实例朝向移动，不记录历史飞行轨迹。

```js
const projectile = await createEffect(fireballText, { scene }); // 魔种替换为 soulSeedText
projectile.root.position.copy(actualPosition);
projectile.root.quaternion.copy(facingRotation); // +Z 对齐飞行方向
projectile.update(dt);
// 命中／击毁结果已经由 Gameplay 确认后：
projectile.setState('dissipate'); // 火球 0.40 秒，魔种 0.65 秒
// 立即移除则 clear()；实例不再复用时 dispose()。
```

active 没有自动消失期限。尤其魔种只有被击毁才结束；接触是否伤害及其生命由 Gameplay 决定，不能用计时、容量或视觉淡出替代这些规则。每个魔种独立实例，播放器不限制总实例数、不覆盖最早实例；每个魔种 35 雾片／3 个绘制批次。临时页已检查 100 实例播放和回收，约 300 个特效绘制批次；这不代表无限累计的游戏性能保证，后续优化不得暗中设置玩法数量上限。

## 裂空斩：可变扇形红刺

`effects/chaos/vfx_chaos_rift_spikes.vfx` 包含扇形预警、参差红刺和黑色缠绕魂气，按 2026-10-06 用户要求替代原工作项的弧形斩光。效果位于地面 XZ 平面，原点是扇区顶点，+Z 为中线。独立设置角度和长度，不附着会随挥斩扭动的 Body 或斧刃节点。

```js
const slash = await createEffect(riftText, { scene });
slash.root.position.copy(groundOrigin); // 混沌脚底／玩法给出的扇区起点
slash.root.rotation.y = lockedYaw;     // 锁定瞄准方向
slash.setSector(angleDegrees, lengthMeters);
slash.setState('warning');             // 蓄力开始；不会自动进入释放
// 现有 RiftSlash 动作到 0.80 秒，且技能没有被打断：
slash.setState('erupt');
// 每帧 slash.update(dt)；中断用 slash.clear()，销毁用 slash.dispose()。
```

`setSector` 接受有限角度 **1°～360°** 与正长度（最大 10000 米为输入校验边界），默认 60°、8 米；当前临时页常用调整范围为 1～16 米，建议按实际 Gameplay 范围传值。长度指顶点到外弧的半径；`root.scale` 保持 1，调用接口可改变覆盖范围而不把红刺高度一起拉长。预警边界、红刺和魂气随同一扇区更新；不自动投射地形，当前用于平地。

红刺高 0.65～2.40 米，分布由固定 seed 决定，长度／角度改变时重新分布。由内向外长出，erupt 开始约 0.28 秒成形，1.55 秒后进入 finished 隐藏。因此与现有 0.80 秒出斧、1.08 秒主要命中参考衔接；伤害窗口仍由 Gameplay 的 [0.94,1.23] 秒规则控制。红刺不是飞行投射物，不添加额外碰撞物或持续伤害。

单实例最多显示 192 根刺，按扇区面积调整数量，高范围下变稀疏；这是图形预算，不限制命中目标数或技能实际范围。预警、红刺、魂气共 3 个绘制批次。清除预警后不会自动补播破地。

在 [火球／魔种／裂空斩临时审阅页](../../ForgeKit/.qa/fire-chaos-effects.html) 中，火球与魔种独立显示，裂空斩与正式混沌模型及 RiftSlash 动作组合，可拖动时序、调角度／长度和测试中断。

2026-10-06：五项特效已交付，其中毒箭及三款火系已验收，暗影袖箭待验收，模型沿用已验收的五件 GLB。每个 `.vfx` 的 binding 记录对应模型 ID 与 `VFX_Anchor`，不需要节点动画，也不把模型复制进特效包。详见 [模型与特效组合预览](../../ForgeKit/.qa/projectile-effects.html)。

| 模型 | 特效路径（相对 Assets） | 外观／粒子片数 |
| --- | --- | --- |
| FSA_PRJ_001_PoisonArrow | `effects/poison/vfx_poison_arrow_trail.vfx` | 绿毒尾雾；25 片 |
| FSA_PRJ_002_ShadowDart | `effects/shadow/vfx_shadow_dart_trail.vfx` | 紫黑影迹；27 片；C1／D1 共用 |
| FSA_PRJ_003_SeekingFirebolt | `effects/fire/vfx_fire_seeking_bolt.vfx` | 橙红尾焰与亮黄焰心；30 片 |
| FSA_PRJ_004_FireSeed | `effects/fire/vfx_fire_seed_aura.vfx` | 水晶包裹火气与向上短火舌；30 片 |
| FSA_PRJ_005_Meteor | `effects/fire/vfx_fire_meteor_trail.vfx` | 岩体燃烧与长尾焰；81 片 |

```js
// projectileModel 已从匹配的 GLB 加载并加入场景。
const fx = await createEffect(vfxText, { scene, model: projectileModel });
// 播放器自动挂在真实 VFX_Anchor 下，局部变换为单位变换。
// 只需由宿主更新飞行模型的位置／朝向／等比缩放，再推进特效：
fx.update(dt);
// 命中、击毁、落地或转化等真实状态要求结束时：
fx.setState('dissipate'); // 0.45 秒后 finished
// 立即清除用 clear()；释放实例用 dispose()。
```

不要重复加模型文件中记录的槽位偏移，也不要既挂父节点又写入槽位世界矩阵。槽位父部件包含旋转／缩放补偿，播放器使用实际层级变换，测试已覆盖整体平移、旋转和 1.7 倍等比缩放。每件模型实例各自创建一个效果实例。

active 持续至程序结束；所有尾迹是**附着在槽位的局部短尾焰／尾雾**，不会在曲线路径上保存历史轨迹。方向性特效沿 -Z 向后，火种以中心槽包裹并沿局部 +Y 升起火气。当前不含命中爆炸、陨石落点预警、落地爆炸或火种转化表现，这些仍由原工作项跟进。

若先隐藏／移除整个模型，子特效也会一起隐藏／移除；需要看到 0.45 秒淡出时，应保留宿主层级至淡出结束，再 dispose 和回收模型。也可立即 clear 后整体回收。特效 dispose 只释放特效资源，不释放模型材质或几何。

## 瘴疫兽毒伤回血反馈

`effects/poison/vfx_poison_plague_heal.vfx` 为全身绿色回流雾光与细小光点，和毒素护盾的能量壳分开。原点为角色脚底，+Z 朝前，单位缩放；尺寸已按 3.96 米瘴疫兽制作，不要重复乘模型的 2.2 倍根缩放。通过单位缩放的跟随组同步角色世界位置／朝向，`createEffect(text,{scene:followGroup})` 创建；不依赖模型材质，不改角色颜色。

初始 heal 播放 1.25 秒后 finished 隐藏。宿主仅在实际正值回血已结算后调用 `setState('heal')`，逐帧 update；连续回血可重播同一实例，不叠加无限实例。预加载后先 clear，收到回血事件再 setState；死亡／中断时 clear，回收时 dispose。视觉不决定回复数值、不消耗玩家毒素；现有猛毒拳按实际命中和毒伤层数结算，不能凭空砸或仅存在毒伤而播放回血。

在 [毒系组合审阅页](../../ForgeKit/.qa/poison-effects.html) 选择“瘴疫兽 · 毒伤回血”，可查看身体、双臂至脚部的回流效果。毒箭与回血特效均归 [毒系技能表现工作项](../Production/Plan/Art/05-完成项/22-毒系技能表现.md) 管理。

## 制作与预览

主入口为 [ForgeKit 特效专用预览器](../../ForgeKit/previewer/effects.html)，与模型动画预览分开。支持打开 `.vfx`、选择 generated 目录、参考模型与动画、火毒状态、时间轴、亮暗背景、多实例及隔离控制。

正式源与贴图保留在 ForgeKit 的 `assets/FSA(项目使用)/definitions/effects`。修改后校验、编译、同步，不直接编辑游戏内 `.vfx`。格式、图层和命令见 [特效管线规范](../../ForgeKit/rules/EFFECTS.md)。原溅血独立预览只保留为回归入口，已改为读取同一个 `.vfx` 和共用播放器。

2026-10-06 调整：毒箭、袖箭、追魂火弹的 VFX_Anchor 已前移至模型根坐标 [0,0,0.38]、[0,0,0.20]、[0,0,0.24] 米，朝向与缩放保持单位变换。五款特效依次按初版尺寸放大 2／1.5／2／2／2 倍，倍率已烘焙到特效定义，接入时不要再次乘该倍率。模型实体尺寸不变；火种与陨石槽位不变。

## 炎巫技能特效（2026-10-06）

五款已获美术验收，正式游戏未接入。路径与时长见配置表；模型组合见 [炎巫临时预览](../../ForgeKit/.qa/flame-witch-effects.html)。这些角色特效不声明静态模型 binding；创建时由宿主传入正确父级。

- **炎魔咆哮：** vfx_fire_flame_roar。创建在世界场景或战斗局部父级；将 root.position 设置为 Fireball_Muzzle 在该父级中的位置，root.quaternion 将局部 +Z 转到技能锁定方向。只跟随起点，不把武器抖动当成重新瞄准。每次距离变化调用 setBeam(length,width)，默认 8／0.85 米；长度为 0 时隐藏，长度与宽度独立，不要用非均匀 root.scale 拉伸。长度允许 0～10000、宽度大于 0 且不大于 10000，单位米；固定 288 雾片，长距离可能变稀，当前预览覆盖 2～18 米。末端为软火舌，不是精确碰撞边界。active 不自动结束；FlameRoar 的 0.20 秒开始，1.40 秒关闭，中断立即 clear。dissipate 仅供程序选择视觉淡出，不能延长伤害窗口。
- **施法护盾：** vfx_fire_meteor_shield，scene 传角色根，原点为脚底，不再上移。按 C3 原始比例和完整 Charge 循环测量，椭球中心 [0.14415,1.78686,0.08198]、半径 [1.04546,2.43316,0.78885] 米，包含举起的法杖。active 持续；hit 自动回 active；broken 和 dissipate 结束到 finished。只有真实盾状态驱动切换，不能凭视觉命中扣盾。
- **蓄力杖焰：** vfx_fire_staff_charge，scene 传 model.getObjectByName('Staff_Grip_R')，不挂 Staff_Tip。资产局部 +Y 沿整根法杖，从杖身到杖冠均有火焰；无需修改模型槽位。active 覆盖实际蓄力期间；完成或取消后 dissipate 或 clear。
- **原地爆炸：** vfx_fire_hellfire_explosion，世界旧位置地面中心创建，root.scale.setScalar(实际半径)。名义半径 1 米，柔软火舌边缘不作命中边界，视觉向外扩张；explode 1.15 秒后隐藏。保留旧位置，不随传送角色移动；一次实际爆炸只触发一次。
- **落点余焰：** vfx_fire_teleport_arrival，scene 传角色根，脚底原点单位缩放；成功传送后立即 setState('arrival')，与 0.90 秒 TeleportRecover 同播并衰减，覆盖头、身体、双臂与袍脚。只跟随角色根，不把它当作爆炸、持续灼烧或伤害事件；死亡／中断 clear。

创建即显示初始状态，预加载后等待事件时须 clear；收到事件再 setState。结束实例可重播或 dispose，纹理和几何由共用播放器管理。通用预览器只看特效自身，组合临时页负责演示挂接。

**左手普攻魔弹：** Attack2 本地 0.76 秒，从 Cast_L 世界位置生成；+Z 按发射方向旋转，之后由投射物独立更新。附带的黑紫尾粒随实例运动，不记录世界历史轨迹。命中、寿命、销毁均由 Gameplay 决定，active 无内置自动消失。

**魔化与全身蓄力：** scene 可传角色根，脚底原点，默认按 D1 3.60 米骨架基准制作。魔化初始 transform 为 1.20 秒的魂气扩散，之后保持 active；若直接恢复魔化状态可 setState('active')。实际体型增至 1.3 倍时随角色父级缩放即可，不再给特效额外乘 1.3。若在世界场景创建，复制角色实际均匀缩放一次。效果不修改模型、生命、攻击或移速，永久魔化保持 active 直到程序取消。通用暗红蓄力复用 body_charge，蓄力时长不由 2 秒视觉循环决定。

**地狱之手：** 地狱之手前置约 0.8 秒蓄力后，HellHand 本地 0.40 秒开启吸引，最长吸引到 10.40 秒。特效原点跟随 Cast_L，+Z 对齐技能锁定方向，不能把身体后仰／抖动用于改变吸引方向。setSector(angleDegrees,radiusMeters) 调整扇区，角度 1～360°、半径大于 0 且不超过 10000 米，默认 75°／9 米；当前组合演示覆盖 5～180°、1～16 米。该半径从视觉左掌顶点量起，接入时须与玩法采用的扇区顶点保持一致。黑洞核心尺寸独立于扇区半径；固定 510 粒子／雾片、6 批次，范围很大时密度会降低，柔软边缘不作为命中判定。正常结束可以 dissipate，破盾立即 clear，并取消后续地狱之眼；资产无自动接招。

**地狱之眼：** 左手蓄力独立创建 hell_eye_charge，跟随 Cast_L 的位置但保持局部 +Y 朝上；进入撑地阶段，把位置投影到实际地面并略抬高，不能直接使用低于地面的挂点高度。HellEye 本地 1.50 秒关闭手部蓄力并另行触发 hell_eye_blast 的 erupt；爆炸取 Boss 的地面位置，局部原点脚底、单位名义半径，root.scale.setScalar(实际范围半径)。魂气自下而上，2.20 秒后隐藏，柔软外缘仅供视觉；缩放同时改变喷涌高度，不自动造成伤害／击飞／回血。

**恶魔追击飞行斩击：** 横劈／竖劈分别在对应动画 0.80 秒触发，最终劈在 1.20 秒触发；起点可取当时 AxeBlade_Top 与 AxeBlade_Bottom 世界坐标的中点，方向取技能锁定朝向。横劈位于局部 XZ 平面，竖劈／最终劈位于 YZ 平面，三款共同以 +Z 为飞行前方；直接选用对应文件，无需再旋转 90°。三款弧顶为原点，弧翼向 -Z 后掠；横／竖主体跨度约 4 米，含软雾边缘，最终劈约 6 米，1.5 倍已写入资产，不能重复乘倍率。持续 active，位移、速度、碰撞范围与回收由程序控制；不可击毁和按近战结算仍是玩法规则。

**恶魔追击瞬移：** 同一个 pursuit_teleport 提供 vanish／arrival 两个显式状态。vanish 0.50 秒配合 DemonPursuitVanish 起势，在旧位置收束；动画 0.50 秒由程序确认合法落点后才移动并切换 arrival，0.65 秒余影渐散。可复用实例或旧／新位置各建实例，脚底原点，按实际体型缩放。传送失败不播放成功落点余影；资产不移动或隐藏角色、不寻找落点。

所有效果的 clear／dispose 与旧资产一致；消散状态只影响画面，不延长实际伤害或吸引窗口。无需为单款特效增加独立播放器脚本。

### 地狱之手／地狱之眼修订与组合预览

地狱之手已内置红色扇形地面警示，不需要程序另画。警示与吸引共同使用 setSector(angle,radius)。保持特效根仅绕 Y 轴朝向目标，起点跟随左掌；每次起点高度变化后调用 setGroundOffset((地面世界高度 + 0.025 - 根世界高度) / 根均匀缩放)，将警示投影到平地。默认地面偏移 -2.5 米仅供独立预览。吸引向下张开约 45°，到达该地面高度后沿地面汇入，不再只有掌高附近的窄层；上方保留较薄空间范围。该接口不提供坡地贴花或地形采样，实际地面高度由宿主提供。

地狱之眼增加 warning 状态：插地蓄力期间显示红色圆形区域；到 HellEye 本地 1.50 秒由程序切换 erupt，不能靠预警自动释放。erupt 已改为 2.20 秒：固定区域内的紫黑魂气从地表下逐渐升出、形成高低错落的魂雾，随后散掉；不再用横向快速扩张制造突然爆开的感觉。范围圈持续到消散阶段后随之淡出。资产根位于地面，默认圈偏移 0.025 个局部单位；可调用 setGroundOffset(0.025 / 半径) 维持世界 2.5 厘米偏移。

临时预览新增两项完整流程：
- 地狱之手 → 地狱之眼：0.8 秒蓄力、0.4 秒前伸、10 秒正常吸引、1.5 秒插地圆形预警、2.2 秒魂气涌出消散。演示正常衔接；破盾仍须 clear 并取消后续。
- 恶魔追击六连击：每段 0.5 秒瞬移前摇，切换示例落点，再依次横／竖／横／竖／横／最终劈；普通段 0.8 秒发射、最终段 1.2 秒发射。各段飞行波独立保留和淡出，可反向拖动时间轴复看。落点与飞行速度是预览示意，不改变技能配置。

### 混沌吞噬毒／火技能补充

### 武器火／毒附魔方向试样

四款 `vfx_enchant_{ak|knife}_{fire|poison}` 位于 `effects/equipment/`。AK 绑定 FSA_WPN_AR_001_Vanguard，军用匕首绑定 FSA_WPN_Melee_001_Fang，均挂 Asset 根、单位缩放。创建时传入实际 model；仅使用粒子，不修改模型材质；枪械粒子位于机匣／护木两侧，粒子位置按这两款模型制作，不能直接当作所有武器的通用适配。

active 持续播放稀疏火焰／毒雾粒子；实际攻击事件调用 setState('attack')，0.32 秒后回 active。解除附魔可 dissipate（0.40 秒）后清理，或立即 clear／dispose；整个播放过程保持原材质。装备实例一次只启用一种元素，替换时先清理旧实例；效果不决定附魔成功、伤害、状态施加或消耗。

[四款组合预览](../../ForgeKit/.qa/enchant-study.html) 提供原模型对照、攻击增强循环与近持视角。近持视角不含手臂与正式攻击动画。定制与通用八款均已验收，正式游戏未接入；护甲无独立资产，其他武器挂接由后续接入适配。

### 通用枪械／近战附魔（四款新增，定制版保留）

资产为 `effects/equipment/vfx_enchant_{firearm|melee}_{fire|poison}.vfx`。无 binding、无材质轨道，不依赖武器名称或节点前缀；挂接位置和尺寸由武器配置提供。每款 40 粒子，枪械 5 个图层，近战 4 个图层。active／attack／dissipate 与定制版一致。

- 枪械：原点是机匣／护木的覆盖中心，+Z 沿枪身朝前，+Y 朝上。单位缩放的发射区约宽 0.10、高 0.05、长 0.32 米，火舌／软雾会超出发射区。优先覆盖枪身，不必对准枪口。
- 近战：原点是刀刃／攻击部位覆盖中心，+Z 沿刃长，+Y 朝上；单位发射区约宽 0.032、高 0.061、长 0.20 米。长刀可拉长 Z，宽斧可增加 X；双刃或不连续攻击部位可重复挂接同一资产。
- `createEffect(pack,{scene:weaponMount})` 创建后，用 `fx.root.position` 设置局部覆盖中心、`fx.root.rotation` 对齐轴向、`fx.root.scale.set(宽倍率,高倍率,长倍率)` 调整尺寸。不需要专用武器代码或改包。缩放也会影响雾片形状，跨度过大建议多个实例分段覆盖；不会自动识别模型表面或避开瞄具。
- AK 演示偏移 `[0,0.13,0.10]`，匕首偏移 `[0,0,0.21]`，均相对 Asset 根，单位倍率。这些偏移只属于预览适配配置，不写入通用资产。宿主父级有实际模型缩放时不要重复乘倍率。
- 定制 `ak`／`knife` 四款原样保留，同一位置选择通用版或定制版之一，避免重复叠加。正式游戏尚未接入。

[附魔组合预览](../../ForgeKit/.qa/enchant-study.html) 前四项是定制版，后四项是通用版；宽／高／长滑块仅调整通用版，保留原模型对照和近持视角。
