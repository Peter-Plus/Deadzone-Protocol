# 03 · 室内外随机物品投放验证

双击 [Play.html](Play.html)。所有程序、Three.js、Rapier WASM、三种建筑、A1/B2 敌人、第一人称双臂与动作均已内嵌；无需服务器、联网或修改浏览器安全策略。已在 Chrome 的真实 `file://` 地址测试。独立实验，未接入正式游戏。

## 操作

- 世界 seed / 生成：重新生成 160 × 160 m 地形、15 栋建筑、30 敌人和物品。原 02 的巡逻、追击、50 敌人档、运动案例与调试图层仍可用。
- 物品 seed / 重投：只替换方块；地形、建筑、角色和当前模拟状态不变。重投采用世界的**初始出生占位**，运行中走过方块允许；不追着移动角色重放物品。
- 物品列表 / 定位观察：去顶观察选定物品，画面顶部显示 ID、所属建筑/区域和世界坐标。
- 玩家走近：当前玩家沿真实导航向所选物品的接近点行走；抵达后点击“第一人称进入”。动态人群仍可能挡住玩家，可恢复巡逻或重置。
- 第一人称：WASD 移动，Shift 跑步，方向键或右键拖动观察；点击画面请求鼠标锁定。鼠标锁定授权仍需人工交互确认。
- 区域/禁放：青色为合法候选矩形，红色为继承的入口、坡道及通路禁放范围。物品 ID 为可选标签；默认隐藏，避免遮挡。
- 区域统计：请求 / 成功 / 失败；悬停行可看规则和拒绝原因。**候选拒绝次数不等于最终缺额**。总览显示实际/请求数量。
- 导出清单：保存当前物品、完整配置及初始角色布局 JSON。方块不带碰撞刚体，没有拾取、背包、品质或掉落经济。

## 配置与优先级

主要配置：[config/placement.json](config/placement.json)。尺寸默认 0.32 m，物品间距采用外接球半径之和加 minGap=0.42 m，初始角色外加 actorGap=0.25 m。局部区域来自 01/02 的空间契约；区域细分必须完全包含于原区域内且互不重叠。模板与建筑不变。

| 规则 | 默认示例 |
| --- | --- |
| through 室内 | red，4–5 个/实例 |
| bent 室内 | blue，4–5 个/实例 |
| warehouse-south | green，2 个/实例 |
| warehouse-north / north 标签 | yellow，2 个/实例 |
| A-1 实例覆盖 | purple，4 个/区域，覆盖原模板和子区域颜色 |
| outdoor-white | white，20 个 |
| outdoor-mixed | cyan:orange = 3:1 权重，20 个 |

颜色只是测试 ID。修改某类建筑仅生成一种颜色，例如将 template-A-red 的 `colors` 改为 `{"blue":1}`。`count` 可为非负整数或 `[最少,最多]`；零数量合法。规则可单独覆盖 size、minGap、actorGap。修改后运行构建，再重新打开 HTML。无需通用配置编辑器。

规则按固定分值选择唯一赢家：instanceId=100、regionId=20、tag=10、templateId=2，相加排序；kind 是过滤条件。实例始终胜过所有非实例规则，区域胜过标签，标签胜过模板。同最高分冲突报错，与数组遍历顺序无关。未知模板/实例/区域/标签、越界细分、负数量、非正/非有限权重等报错。未匹配规则的区域不投放。禁放范围来自模板的 exclusions，任何颜色规则都不能覆盖禁放约束。

## 空间策略

室内先在局部区域随机采样再按实例 Y 旋转和平移；中心高度为地板上表面加半高，盒体跟随建筑旋转。室外使用实际三角高度场的高度与法线，方块底面随坡倾斜；只接受整块底面在同一平面上的位置，跨折线候选重试。检查八个顶点、墙/屋顶体积、入口与通道缓冲、间距和初始占位。

物品有单独的接近点（玩家胶囊能站立且靠近物品），要求从出生点连通，并能通过无墙线段接近。每区域首个路径可达点作为缓存锚点，后续须与锚点连通。独立验证使用 Rapier 实际碰撞盒与地形、9 个底面射线、接近点胶囊和从出生点重新求得的完整路径。

独立随机流：`rng(worldSeed + ':' + placementSeed, 'loot.v1:' + regionKey)`。world 1.0.0、placement 1.0.0、配置、两个 seed、初始敌人数共同确定结果；时间字段 generationMs 不参与稳定清单比较。只改变物品配置/seed 不消耗世界或敌人的随机流。

每区域最多 `min(requested × attemptsPerItem, maxAttemptsPerRegion)` 次采样。默认请求约 100 个，容量不足如实报告失败，不越界补数。3 个代表 seed 实际 99/105、101/106、103/109；狭小房间受间距与敌人占用限制，数量缺额属于显式输出。

## 独立命令

在本目录执行（只读复用游戏已有 node_modules，不安装新依赖）：

```powershell
node src/build.mjs
node src/verify-placement.mjs
node src/browser-placement.mjs
node src/browser-views.mjs
node src/finalize.mjs
```

`npm run check` 包含 30 seed 自动检查和重新构建。浏览器脚本使用本机 Chrome、临时 profile、真实 file://，全部证据只写本目录。CHROME_PATH 可指定 Chrome 路径。若执行环境阻止 GPU 子进程，应允许测试进程正常运行；不能关闭浏览器安全策略替代验收。
