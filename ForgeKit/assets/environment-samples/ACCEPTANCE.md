2026-10-05。范围为 ForgeKit 类型规范、共用流水和样件；未接入正式游戏地图，也未重复制作已完成的大型交互设施。

## 已执行检查

在 ForgeKit 根目录执行：

```powershell
node tools/environment/build.js
npm test
node tools/environment/verify-physics.js
node tools/environment/verify-browser.js
```

- ForgeKit 测试共 74 项通过，其中 7 项环境测试覆盖五类定义、错误声明拒绝、门动画与碰撞不一致拒绝、地形三角形与高度查询一致、建筑坡道与堵墙、统一实例变换、实际门动画及实例隔离。
- Rapier 0.21.0 实际碰撞共 18 案例通过：三种胶囊量规 × 三个建筑摆放角度，以及三种量规 × 门关闭／开启／动态开启。使用游戏已安装依赖，只读加载；没有安装新依赖或修改游戏运行时代码。
- Chrome 真实 file:// 自包含预览通过：五模型加载、去顶查看室内、B2 通路、门四个动画进度与碰撞对齐、按钮播放和重置、重复切换后的资源稳定。没有外部网络资源请求或页面脚本异常；重复切换前后渲染几何数相同。
- 已检查七张截图，包含五类样件、去顶室内和打开的铁门。碰撞线框与空间标记可独立关闭。

证据保存在 ForgeKit [.qa/environment](../../.qa/environment/)：`physics.json`、`browser.json` 和 PNG 截图。浏览器首次受执行沙箱限制，GPU 子进程无法启动；在允许正常启动子进程的环境重跑后通过，没有关闭浏览器安全策略。预览文件本身可双击，无须特殊启动参数。

## 验收中修正

- 修正围墙装饰节点的非法命名，由原模型校验器准确拒绝。
- 扩大建筑入口外部落脚预留及门外预留，避免 B2 的中心虽在范围内、完整体积却越界。
- 屋脊纳入屋顶分组，去顶预览一并隐藏；地形增加真实三角网线框，便于查看缓坡。
- 门扇覆盖门框净开口；活动碰撞始终跟随真实动画位置，不在交互瞬间消失。

## 实用边界

2026-10-06 更新：普通建筑样件地坪由 40cm 降为 10cm，前后坡板已移除，屋顶、墙体及上梁同步下移以保持室内净高；重新执行 ForgeKit 全部 84 项测试、18 个实际碰撞案例和离线预览检查，均通过。空间检查区分向上小台阶与向下小落差，物理验证开启自动跨步和贴地。之前坡道版本的说明属于历史，当前产物以低门槛版为准。此修改未接入游戏正式运行时。

这些是低细节规范样件，后续还需正式美术制作。量规沿用旧 Test 的保守范围，尚未对最新全部角色动画重新测量；正式建筑需再做实际模型和动作复核。

空间检查验证的是定义中声明的单体通路；物理案例是单个胶囊沿给定路径移动，不是完整敌人 AI、任意位置自动寻路、多敌人拥挤或正式保护区导航更新。墙段连接数据不等于已完成整圈围墙封闭验证。

v1 不包括多层、攀爬、旋转/升降门、可破坏建筑、凹网格碰撞、复杂道路材质混合或无限地形。原 Test 基线、FSA 正式库、游戏 Assets 和 Play.html 均未由本次改动覆盖。后续正式美术项可引用本次规则与样件，避免重复编写基础工具。
