# 五件护具世界拾取模型

### 五件护具世界拾取模型（2026-10-05）

军用盔、特种兵头盔、防弹衣、特种兵护甲、军用靴已交付为独立静态 GLB；文件路径见资产配置表，源定义位于正式 FSA 库 definitions/models/armor。军用靴包含左右两只，为一个资产、一个拾取物，不要重复生成两双。

- 米制、+Y 向上、+Z 为脸部/胸部/鞋尖方向，默认 scale=1。原点在左右中线、模型最低点的地面投影基准，最低几何 y=0；头盔最低点包含下颏带。默认姿态为直立展示，可直接放在地面；倾倒摆放时由实例变换并重新计算贴地高度。
- 头盔为分片式空心盔壳，下方开放；防弹衣和护甲由前后片、侧围和肩带组成，保留颈口与臂孔。军用靴的靴口采用暗色内衬表现，无腿部几何。颜色与轮廓用于区分型号，不内置品质、属性或元素规则。
- 模型内嵌不透明材质，无外部贴图、骨架、动画或装备挂接插槽；不作为完整穿戴模型。未包含拾取碰撞体、触发范围、漂浮旋转效果、品质光柱和附魔特效；这些由运行时单独配置。
- 各资产保留独立部件，实际三角形与部件数见正式库 docs/ARMOR_WORLD_PICKUPS.md。未进行多拾取物场景性能测试，批量实例化或合并静态部件须由表现层按材质处理。
- 已通过正式定义校验、实际 GLB 尺寸/底部/材质/有限变换检查和正反面浏览器预览；正式产物与游戏 Assets 副本逐字节一致。拾取、背包、装备数值和附魔仍待接入。
