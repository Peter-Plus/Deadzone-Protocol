# 六种备用弹药包装

### 六种备用弹药包装（2026-10-05）

依据 Design/Item/武器弹药配置表（临时）.md 交付六个独立封闭包装 GLB：7.62mm、5.56mm、.50 手枪弹、12 号霰弹、9mm、.338 狙击弹。正式源在 definitions/models/items/ammunition，资产路径见配置表。

- 这是背包备用弹药的世界拾取包装，不是单颗子弹、弹壳、弹匣或射击投射物模型；不按库存数量逐颗生成。各包装没有固定装弹数量，数值与容量由 Gameplay 配置。
- 7.62mm 共用 AK-47 战术 / M14-A；5.56mm 对应 M249-E4；.50 对应 DE-50 战术；12 号对应 M870-C；9mm 对应 MP5 战术；.338 对应 M24-A3。此映射沿用临时设计，不创建按武器区分的 7.62mm 子类型。
- 米制、+Y 上，+Z 为口径标签面；原点在包装底面中央，最低 y=0，默认 scale=1。六种包装通过尺寸、颜色、封带/提手/护边与立体口径标识区分；标签数字表示口径，底部和背面条纹只是装饰，不表示弹量或品质。
- 六件均为封闭静态模型，内嵌不透明材质，无贴图依赖、骨架、Socket、开盖节点或 AnimationClip。没有可视散弹、内部弹药、开盒演示或额外武器模型。
- 已检查正式定义、六个实际 GLB 的尺度/落地/有限变换/材质、正反面预览与逐字节同步一致性。弹药拾取、堆叠、容量计算、补弹和武器映射尚待运行时接入。
