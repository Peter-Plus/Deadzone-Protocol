# 混沌专用动画

### D1 混沌：五段定制动画与外部事件（2026-10-05）

五段动画使用 humanoid.v2，显式驱动十三节点，按当前非对称混沌模型制作。模型、关节位置、九个插槽和右斧握持定义未修改。准确路径统一见资产配置表，片段名为文件名去掉 .anim.glb 后缀。Body 使用 canonical-local 平移，播放前通过 ForgeRuntime.prepareClip 重定到混沌的 1.55 米基准；v2 到 v2 不需要旧版本适配。

| 动作 | 时长 | 循环 | 动作说明 |
| --- | --- | --- | --- |
| Idle / 待机 | 3.60 秒 | 是 | 微驼背、左臂外展且掌心斜向内，右手低位持斧；呼吸和重心摆动。 |
| Attack1 / 右斧近战 | 2.05 秒 | 否 | 举斧蓄势、腰肩转体斩击、双腿缓冲并收招；0.92 秒命中参考。 |
| Attack2 / 左掌发射 | 1.85 秒 | 否 | 抬起左臂、翻掌朝向正前方，0.76 秒发射后短促回震，再收回。 |
| Hit / 受击 | 0.54 秒 | 否 | 小幅躯干回缩和头部滞后，0.09 秒峰值，不作大幅踉跄；末帧回稳。 |
| Death / 死亡 | 4.80 秒 | 否 | 1.30 秒跪地，停顿失力后向前倒下；3.85 秒起保持倒地，巨斧随手平放。 |

**Idle 与衔接：** 默认战斗姿态略驼背，头部仍看向前方；左臂外展前举、手指向下，掌心斜朝内侧，避免巨手贴入腹部。右斧低位戒备。呼吸、轻微转体和重心变化形成 3.60 秒循环；首尾完全闭合。Attack1、Attack2、Hit 的首尾与 Idle 循环边界一致，Death 首帧也从该姿势出发。常规切换建议 0.10–0.16 秒短混合；从 Idle 任意相位切入无需等待循环结束。五段均为绝对姿态片段，不直接作为 additive 动画。

**Attack1 / 右斧近战：** 0–0.42 秒举斧并转腰蓄势，0.42–0.60 秒短暂蓄住；0.60–1.08 秒肩、肘、腕与躯干一起斩下，左臂外展平衡，双腿参与缓冲。1.08–1.34 秒留出重势，随后收回至 2.05 秒。建议命中窗口为 [0.78,1.04] 秒，0.92 秒为主要命中参考。读取 AxeBlade_Top / AxeBlade_Bottom 的世界位置做扫掠参考，每次攻击对同一目标去重；范围与伤害由 Gameplay 决定。巨斧始终内置并挂在右手，不重复加载武器。

**Attack2 / 左掌发射：** 0–0.55 秒前伸左臂与翻掌同步完成，0.55–0.76 秒掌心正朝角色 +Z，手指朝 +Y。在 0.76 秒从 Cast_L 的世界位置提交一次发射；此刻 Cast_L 的局部 +Z 经世界四元数变换后即为掌心朝前方向。0.76–0.98 秒先回震、再轻微反弹并稳住，只有一次发射，不随抖动重复发射。1.20 秒起收势，1.85 秒回准备姿态。瞄准、弹种、吞噬元素与投射物由 Gameplay 配置；不能用 Attack_L 的轴或巨臂骨骼的 +X 代替掌心法线。

**Hit / 轻受击：** 0.09 秒到达峰值，躯干相对准备姿态只旋转约 5–6 度，头稍滞后，双臂稳住；0.54 秒回稳。Boss 是否硬直、是否允许打断攻击由游戏状态判定；受到伤害不等于必播 Hit。可打断时使用约 0.04–0.06 秒短混合，不等原动作结束，也不以动画峰值延后伤害结算。

**Death / 跪地后倒下：** 0–0.38 秒失力低头，0.38–1.30 秒屈双膝落地；1.30–1.85 秒明确保持跪姿，1.85–2.55 秒上身继续低垂，2.55–3.85 秒缓慢向正前方倒下，头转向一侧，左臂落在外侧，右腕带着斧面转平落地。3.85–4.80 秒保持尸体姿势。1.30 秒可接跪地音效，3.85 秒可接躯干落稳音效，二者都不是额外伤害事件。Root 有倒地旋转但没有平移；必须保留 Root 旋转轨道。只有 Body 含规则允许的小幅位移，没有 Root Motion 或导航位移。

死亡状态优先：立即取消未发生的攻击/发射事件和命中窗口，按设计立即处理 Boss 死亡与胜利，不能等待 4.80 秒动画结束才结算胜利。Death 使用 LoopOnce、clampWhenFinished，末帧不得切回 Idle、复位 T 形或自动站起。尸体碰撞、生命周期、淡出和掉落由状态机处理。对象池复用时先恢复参考姿态，再启动新动作。

**验证范围：** 五段实际 GLB 各 241 个时点检查十三节点、合法位移、循环/起止衔接、地面高度及左手/斧身对躯干和头部主要体积的穿插，未发现明显穿入。Attack2 发射关键帧的掌心 +Z 与角色正前方一致、手指向上。跪地时膝甲离地约 0.5 / 4.1 厘米；最终胸前约 4.1–4.3 厘米、斧体最低约 5.5 厘米、左掌主体约 8.7 厘米，手指/掌背更接近地面。已逐项检查正侧视图、原 ForgeKit 预览器播放与结束复位，59 项工具链测试通过。接地按当前比例和平地制作，不能推断任意体型、坡地或混合状态均自动贴地；运行时需另行验证。

本次交付五段动画资产和事件约定，未接入敌人动画状态机、命中、投射物或胜利表现。蓄力与三个基础技能动作已补齐，详见下节；专用移动、魔化、吞噬和其他技能动作待后续制作。

### D1 混沌：咆哮蓄力与基础技能（2026-10-05）

本轮追加 Attack2 前伸动作（当前已修订为抬臂同步翻掌），并新增 Charge、RiftSlash、HellHand、HellEye；混沌现有九段 humanoid.v2 专用动作。模型与插槽未变，Idle、Attack1、Hit、Death 内容保持不变。以下时刻均为片段本地秒数；动画文件不包含 Gameplay 事件。

| 动作 | 时长 / 循环 | 节奏 |
| --- | --- | --- |
| Charge / 咆哮蓄力 | 1.20 秒 / 是 | 后仰、抬头咆哮，全身轻颤，首尾闭合；进入时短混合。 |
| RiftSlash / 裂空斩 | 2.65 秒 / 否 | 0.80 秒举斧蓄力后大幅转体斩击，1.08 秒主要命中参考；留出缓冲再恢复准备姿势。 |
| HellHand / 地狱之手 | 10.40 秒 / 否 | 从 Charge 衔接，0.40 秒前伸翻掌后持续吸收 10 秒并轻颤，末姿势衔接 HellEye。 |
| HellEye / 地狱之眼 | 1.50 秒 / 否 | 0.60 秒半蹲侧倾、左手撑地，再抖动蓄力 0.90 秒；1.50 秒爆炸提交参考，无额外收招。 |

**Attack2 修订：** 0–0.55 秒前伸左臂与翻掌同时完成，上身轻微右旋配合，腿部保持原支撑姿势；0.55–0.76 秒掌心正朝 +Z、手指向上，发射口靠近正前方中线。0.76 秒发射、后续短促回震及 1.85 秒回准备姿势不变。位置读取 Cast_L，方向使用其局部 +Z 变换到世界空间，动作不改变技能射程。

**Charge / 咆哮蓄力：** 1.20 秒循环；躯干后仰、头部继续上抬，双臂张开，约 5 Hz 的小幅旋转轻颤。首尾十三节点和 Body 位移相同。它从已就位的咆哮姿势开始，进入时从当前动作短混合约 0.10–0.15 秒，不把 Idle 强插入循环。蓄力持续多久由技能决定；地狱之手使用约 0.80 秒，当前片段 0.80 秒姿势与循环边界一致，可以直接续接 HellHand。其他相位取消蓄力时短混合，不等待循环结束。口部为当前刚性模型外观，动作通过后仰、抬头和身体颤动表现咆哮；不包含音频。

**RiftSlash / 裂空斩：** 本片段自带举斧蓄力，不额外串接 Charge。0–0.50 秒举斧并转体，0.50–0.80 秒保持蓄势；0.80–1.26 秒大幅斩击，1.26–1.65 秒留出重击缓冲，1.65–2.65 秒恢复 Idle 边界姿势。完整斧刃参考点路径约 14.65 米，普攻约 12.18 米，且腰肩转体幅度更大。Gameplay 在 0–0.80 秒显示扇形预警，0.80 秒结束预警；建议近战窗口 [0.94,1.23] 秒，1.08 秒主要命中参考。使用 AxeBlade_Top / AxeBlade_Bottom 扫掠并逐目标去重，高伤和击飞仍按近战规则配置。动作中的转腰不应把整个 Boss 的瞄准方向来回摆动。

**HellHand / 地狱之手：** 首帧精确续接 Charge 边界；0–0.40 秒把左臂伸向前方并翻掌，0.40–10.40 秒保持前向吸收和小幅颤动，持续区间为 [0.40,10.40)，正好 10 秒。片段非循环，没有每秒重新伸手，也没有发射事件。吸引扇区方向由 Gameplay 锁定，视觉起点随 Cast_L 移动；持续阶段掌心法线始终近似正前方，不能让颤动重新追踪或改变吸引规则。

地狱之手蓄力约 0.80 秒后进入 HellHand；吸引激活前先完成 0.40 秒前伸。护盾、SP 损失、禁翻滚和角色移动按技能设计接入；吸引计时从本片段 0.40 秒开始。到达近身目标距离可提前正常结束，不必等待 10 秒。正常结束时关闭吸引与护盾，刷新并立即转入 HellEye；完整结束时两段边界十三节点/Body 位移精确匹配。提前结束时从当前颤动相位短混合约 0.04–0.06 秒进入 HellEye。破盾立即关闭吸引、取消所有后续事件，**不得自动接地狱之眼**；其他取消条件由状态机处理。

**HellEye / 地狱之眼：** 首帧为 HellHand 的前伸姿势。0–0.60 秒屈膝半蹲、身体向左前方深倾，左手转为掌面朝下撑地，右斧留在外侧；0.60–1.50 秒维持接地姿势并约 10 Hz 小幅颤动。手腕略抬指，让掌根参与撑地，避免仅爪尖触地。整个片段 1.50 秒，末帧保持蓄势接地，不额外塞入恢复段。1.50 秒提交一次以 Boss 自身为中心的范围爆炸、击飞和按命中数量回血；按近战处理。技能开始后霸体不可通过破盾/受击打断，自身及召唤物按设计排除。单独施放时从当前姿态在片段起始约 0.06–0.10 秒短混合，仍在本地 0.60 秒撑地、1.50 秒提交，不先完整播放地狱之手。爆炸后由状态机决定以约 0.20–0.30 秒混合回 Idle 或接下一动作。

地狱之眼的 Cast_L 随掌面朝下，可能略低于地表，不能把它用作全场爆炸中心或直接放置地面特效。爆炸中心应由 Boss 实例的地面位置/导航位置确定；掌根接地特效先投影到地面。没有动画 Root 平移、IK、网格或插槽改动；撑地姿态仅靠合法关节旋转和 ±0.20 米内的 Body 位移。

**验证：** 使用实际 GLB，以约 120 Hz 检查修改/新增片段及 Idle、Attack1 参照，共 2800 个时点；未发现左手或斧身明显穿入躯干/头部核心体积，地面最低间隙约 4.7–7.0 毫米。地狱之眼持续段手掌主体距地约 3.5–3.6 厘米，掌根约 0.5 厘米，双脚最低点不超过约 2.9 厘米。已检查 Charge 循环、Charge→HellHand、HellHand→HellEye、裂空斩首尾和掌心方向；原五段动作检查、原预览器九段播放、正侧视图及 59 项工具链测试均通过。检查范围为当前模型和平地，坡地和运行时混合仍需接入验证。

审阅页保持原地址，新增技能选择和“蓄力 → 地狱之手 → 地狱之眼”连播按钮。本轮仅动画资产及事件契约，护盾、吸引、爆炸、伤害与敌人状态机尚未接入。恶魔追击已追加四段，见下节；移动、魔化及其他吞噬技能动作仍按后续需求制作。

### D1 混沌：恶魔追击六连斩（2026-10-05）

新增四段原生 humanoid.v2 动画，全部非循环，显式驱动十三节点；混沌现共十三段专用动画。这里的 a1–a4 是恶魔追击四段动作的顺序别名，准确资产路径见配置表。模型、九个插槽和原九段动画均保持不变。

| a2 / DemonPursuitHorizontal | 1.10 秒 | a2；第 1、3、5 段。横向蓄势挥斩，0.80 秒发射参考，随后 0.30 秒缓冲回稳。 |
| a3 / DemonPursuitVertical | 1.10 秒 | a3；第 2、4 段。举斧竖向下劈，0.80 秒发射参考，随后 0.30 秒缓冲回稳。 |
| a4 / DemonPursuitFinal | 2.00 秒 | a4；第 6 段。更大幅度举斧与全身下压，1.20 秒发射参考，随后 0.80 秒缓冲回稳。 |

**a1 / 瞬移前摇：** 0–0.34 秒缩身、屈膝压低重心、收斧，0.34–0.50 秒保持临界姿势；末帧为三个斩击片段共同的首帧。0.50 秒由 Gameplay 验证合法落点并执行一次短距瞬移，同时更新角色朝向；随后立即从相应斩击的 0 秒开始播放。GLB 内没有瞬移、显隐、Root 位移或导航路径，不能依靠骨骼动画移动实例。首次从 Idle 边界进入时姿势匹配，其他姿态可在 a1 起始 0.04–0.08 秒短混合。

**a2 / 横劈：** 第 1、3、5 段使用。落点就位后，0–0.46 秒把巨斧拉向右后方、转腰蓄势，0.46–0.62 秒蓄住；0.62–0.80 秒向前横斩，0.80 秒为一次斩击波发射关键帧；0.80–0.90 秒继续横向随挥，0.90–1.10 秒缓冲回稳。挥斩关键段斧面保持水平，躯干与左臂配合平衡。末帧与 a1 首帧完全一致，可以直接开始下一次瞬移前摇。

**a3 / 竖劈：** 第 2、4 段使用。0–0.46 秒高举右斧，0.46–0.62 秒蓄住，0.62–0.80 秒纵向下劈；0.80 秒发射一次竖向斩击波，0.80–1.10 秒为随挥与缓冲回稳。斧面和挥击主方向保持竖向，与横劈清楚区分。起止姿势与 a1 的末帧/首帧匹配。

**a4 / 终极一劈：** 仅第 6 段使用。0–0.75 秒更大幅度举斧、后仰蓄势，0.75–0.96 秒蓄住；0.96–1.20 秒全身向前下压斩落，1.20 秒发射终极斩击波。1.20–1.36 秒随挥、1.36–1.60 秒留出重击停顿、1.60–2.00 秒回稳，合计 0.80 秒缓冲。斧刃参考点总路径约 17.88 米，普通竖劈约 15.18 米；终击路径增加约 18%，上下跨度也更大。最后回到准备姿势，由状态机转入 Idle 或其他状态。
