# 炎巫专用动画（humanoid.v2）

### C3 炎巫：六段专用动作与外部事件（2026-10-05）

六段动作使用 humanoid.v2，均原地播放、显式驱动十三节点；模型、装备插槽和现有共用 Cast 未修改。实际路径只在资产配置表维护。

| 动作 | 时长 / 循环 | 动作与事件 |
| --- | --- | --- |
| Attack / 普攻 | 1.10 秒 / 否 | 1.10 秒；单次；法杖前伸朝向前方中线、短促抖动发射，左手配合；发射关键帧 0.42 秒。 |
| Charge / 共用技能蓄力 | 1.00 秒 / 是 | 1.00 秒；循环；高举法杖、抬头，左手保持施法姿势，身体轻颤；首尾一致，各技能复用。 |
| FlameRoar / 炎魔咆哮后段 | 1.68 秒 / 否 | 1.68 秒；单次；首帧衔接蓄力，0–0.20 秒前伸朝向前方中线，0.20–1.40 秒持续抖动，最后 0.28 秒收势。 |
| TeleportRecover / 业火转移后摇 | 0.90 秒 / 否 | 0.90 秒；单次；从已传送到落点的蓄力姿态下沉缓冲、回稳收杖；不包含传送或爆炸事件。 |
| Hit / 受击 | 0.55 秒 / 否 | 0.55 秒；单次；0.085 秒后仰回缩峰值，左手护身、右手稳杖，末帧回到准备姿势。 |
| Death / 死亡 | 1.90 秒 / 否 | 1.90 秒；单次；前倾失衡、向正前方扑倒，法杖保持握持随身落地；1.42 秒起保持倒地，播放结束须停在末帧。 |

**蓄力与衔接：** Charge 全程保持右手高举与抬头，左臂/手掌相对身体保持施法姿势，由 Body 的小幅旋转和上下位移带动全身轻颤，首尾十三节点姿态与 Body.position 完全一致。进入时建议从当前动作短混合约 0.10–0.15 秒，不单独制作举杖前摇；蓄力时长按技能配置决定，不要求等一整圈。FlameRoar 和 TeleportRecover 的第一帧精确等于 Charge 的循环边界姿势；在任意相位结束蓄力时，身体可能处于轻颤的不同相位，后段前 0.04–0.06 秒可从当前整体姿态短混合到后段姿态，不能为了等循环边界拖长技能蓄力。

**普攻：** Attack 从持杖准备姿势前伸，0.42 秒为一次发射事件，随后短促回震并收回；左手随动作抬起配合。时长 1.10 秒，末帧回到准备姿势。

**炎魔咆哮：** 蓄力阶段仍复用 Charge（设计参考 0.5 秒）；后段 FlameRoar 的 0–0.20 秒只做快速前伸，不结算光束伤害。光束持续区间为 [0.20,1.40) 秒，抖动约 1.2 秒；建议四次伤害脉冲为本片段的 0.20、0.50、0.80、1.10 秒，1.40 秒关闭光束，1.40–1.68 秒收势。伤害、附烧、击退与霸体按技能配置实现，GLB 无内置 Gameplay 事件。

**发射位置与方向：** 这两段前指动作建议读取 Staff_Tip 世界位置作为投射物/光束起点。杖身轴是 Staff_Grip_R 的局部 +Y；前指时降低原有上仰，略向内收，使杖轴指向角色前方中线（离角色原点前方 3 米、与握点等高的制作参考点，不代表技能射程）；咆哮持续阶段仅保留小幅抖动。Fireball_Muzzle 的位置及局部 +Z 仍保留，但法杖前倾后它的 +Z 会随杖转向下方，不能直接作为此次光束瞄准方向。普攻目标方向由 Gameplay 求解，咆哮方向在蓄力开始时按设计锁定，持续阶段不随抖杖重新追踪玩家；视觉起点可随 Staff_Tip 移动。

**业火转移：** 前段仍使用 Charge（设计参考 0.6 秒）。旧位置的爆炸与合法落点传送由 Gameplay 在后摇开始前完成；实例放到落点后设置 TeleportRecover 的第一帧再显示/播放。0–0.10 秒轻微下沉缓冲，随后回稳并放下法杖，0.70–0.90 秒保持准备姿势。该片段无根位移、无传送、无重复爆炸或伤害事件；传送取消时不应误播成功落点后摇。

**受击 Hit：** 0.55 秒，非循环，首尾等于普攻的持杖准备姿势。0–0.085 秒躯干短促后仰回缩、头部滞后、左手抬起护身，右手稳住偏斜法杖；0.085–0.17 秒停顿，随后前倾回稳，0.55 秒恢复准备姿势。它是完整十三节点绝对姿态片段，不作为 additive 叠加。由 Gameplay 判定受击硬直/蓄力打断是否成立；从其他施法姿势进入时，可在片段开始的 0.04–0.06 秒内短混合，不等待原动作播完、不以动画峰值延后伤害结算。不可打断状态、护盾命中是否播放仍按技能设计处理。

**死亡 Death：** 1.90 秒，非循环，首帧等于持杖准备姿势。0–0.16 秒前倾失衡，0.16–0.43 秒加深前倾，0.43–1.10 秒向角色正前方扑倒，1.10–1.42 秒轻微回弹后落稳，1.42–1.90 秒保持俯卧、头转向一侧、左手落在身旁。法杖始终挂在右手，随身落地，不脱手、不需要独立道具物理。Root 有旋转，必须保留该轨道；根节点没有平移，Body 的 Y 偏移保持为零，尸体不作导航位移。按当前模型和平地校验接触，坡地贴合由运行时处理。

死亡状态优先于 Hit 和施法：立即取消未发生的攻击/传送事件并关闭持续光束，从当前姿态短混合进入 Death；不先播完 Hit。使用 LoopOnce 并 clampWhenFinished，结束后保持末帧，不能自动切 Idle、恢复 T-Pose 或再次站起。尸体生命周期、碰撞、掉落、淡出及杖芯发光控制由游戏状态负责；GLB 仅含骨骼动画。重新生成角色或对象池复用时恢复参考姿态，再设置新动作。

Attack、FlameRoar、TeleportRecover、Hit 末帧精确一致，均回到持杖准备姿势，可再短混合到共用 Idle 或后续专用 Idle。事件按本地时间跨越触发，每次播放一次；被打断时取消未发生事件，并立即关闭正在持续的光束。盾的消失、技能取消、显隐和传送都由游戏状态控制。
