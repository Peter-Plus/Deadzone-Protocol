# 三类军备箱模型

### 三类可携带军备箱（2026-10-05）

小型普通军备箱、普通军备箱、高级军备箱已交付静态 GLB，路径见资产配置表；正式源定义在 definitions/models/containers/armory。分别采用紧凑弹药箱、较大通用箱、深蓝灰与金色加固箱轮廓。三个模型不是大型神秘宝箱或空投箱。

- 米制、+Y 上、+Z 为带锁扣正面；原点位于箱体底面中央，四脚最低 y=0，默认 scale=1。配置表尺寸包含把手和突出锁扣，不代表背包容量或碰撞形状。
- 均为中空箱体，包含底板、四面箱壁、密封缝、护角、把手、锁扣、铰链和固定箱盖。材质不透明、内嵌且无外部贴图，无发光或奖励内容模型。
- 箱盖固定为普通静态部件，无 LidPivot、骨架、动画或开盖接口。
- 本次仅交付三个闭合静态模型；预览页只提供外观查看，无开盖预览。
- Gameplay 仍按设计配置：小型普通箱 1 类、普通箱 3 类、高级箱 2 类较高价值奖励；高级表示奖池质量，不能从尺寸或装饰推断奖励数量。初始化抽取、容量计算、守敌限制、开启和逐件领取待接入。
