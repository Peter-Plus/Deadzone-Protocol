# FSA 模型资产使用说明

首批交付日期：2026-09-30；敌人扩展更新：2026-10-02。面向游戏项目的资源导入、装备挂接和动画接入。

## 1. 复制与导入

将本目录的内容整体复制到游戏项目的资源目录，保留 `models/` 和 `animations/` 的相对目录结构。本说明中的路径都相对于复制后的资产根目录，与原磁盘位置无关。

当前包含 **18 个模型、33 段动画，共 51 个 GLB 文件**：9 件武器、1 套 FPS 双臂、8 个角色，另有 23 段 FPS 动画、8 段角色共用动画和 2 段角色专用远程动画。环境资产不在本批交付范围内。

```text
资产根目录/
  模型资产使用说明.md
  models/
    weapons/<类型>/<类型_编号_名字>/
    fps_arms/
    characters/enemies/
      common/           A1～A4 普通敌人
      elite/            B1～B3 精英；后续首领可用 boss/ 分类
    characters/npcs/
  animations/
    fps/unarmed/
    fps/firearm/shared/
    fps/melee/shared/
    fps/throwable/shared/
    characters/shared/
```

- 格式为 GLB（glTF 2.0）；模型内含几何和材质，无需另行寻找贴图文件。
- 资产使用米制，+Y 向上、+Z 为模型正前方。若引擎坐标系或单位不同，统一转换模型、动画和插槽，避免分别旋转或缩放造成错位。
- 保留节点名称、层级和局部变换；不要在导入时合并掉动画节点或插槽。不要自动重置模型姿态或把模型中心重新设为原点。
- `.anim.glb` 是独立动画资源，每个文件有一段动画。提取动画并绑定到目标模型的同名节点；场景里显示模型实例，不需要另行显示动画文件的节点树。
- 每个活动角色或双臂对象应拥有独立的动画状态和可变节点实例，避免多个角色互相影响。

## 3. FPS 装备与相机

### 装备挂接

在双臂实例中递归查找以下节点，名称区分大小写：

| 节点名 | 用途 |
| --- | --- |
| `Weapon_R` | 所有玩家手持装备的挂接点：七种枪、近战刀、手雷均使用此点 |
| `Weapon_L` | 左手支撑参考点，无需挂装备 |
| `Camera_FPS` | 第一人称相机的位置与朝向参考 |

挂接武器时，将完整武器实例设为 `Weapon_R` 的子对象，并将武器实例局部位置和旋转清零、缩放设为 1。保留武器内部节点变换，不要额外补偿握把位置。若引擎已作统一单位转换，沿用对应的统一尺度。

持枪位置位于画面右侧，左手位于右手前方、略低处。左手是共用持枪动画的视觉辅助，不需要把同一把枪再约束到 `Weapon_L`。七类枪目前共用 Firearm 动画；近战使用 Melee，手雷使用 Throwable，空手使用 Unarmed。

弹匣、枪机等是静态外观。Reload 和 Bolt 表现为手臂动作，不包含独立弹匣拆卸或枪机活动。

### 相机接入

`Camera_FPS` 是定位节点，不是已经配置好的相机对象。相机采用局部 **-Z** 为前向时，可以在该节点下挂相机并清零相机局部位置、旋转；此时视线朝资产 +Z。若引擎相机采用 +Z 为前向，应转换相机朝向约定，不能直接照搬 -Z 相机的旋转。

初始画面建议使用垂直视野角 **70°**、近裁剪面 **0.005 米**；这是调试构图的起始值，可按项目调整。相机点位已包含后退、抬高的构图偏移。

由玩家视角控制器驱动整个第一人称视图组，再使用该组内的相机点位。若项目已有主相机，可让相机与双臂保持同样的相对关系；选择一种驱动方向，避免相机跟随双臂、双臂又反向跟随相机的循环依赖。相机不应跟随手臂关节的挥动。

双臂通常只对所属玩家的第一人称视图显示；世界中的其他角色使用完整人物模型。

## 4. 动画绑定与播放原则

FPS 与完整角色是两套独立骨骼，动画不能交叉使用：

| 对象 | 动画目录 | 动画绑定节点 |
| --- | --- | --- |
| FPS 双臂 | `animations/fps/` | `UpperArm_L`、`Forearm_L`、`UpperArm_R`、`Forearm_R` |
| A1～A4、B1～B3、罗德 | `animations/characters/shared/` 和角色专用 `overrides/` | `Root`、`Body`、`Head`、`Arm_L`、`Arm_R`、`Leg_L`、`Leg_R` |

这些资产适合按原节点层级播放动画，不需要套用引擎标准完整人形骨架。完整角色没有独立肘、膝和手指节点。导入时选择能保留原节点动画的模式，不要自动强制映射成另一种人体骨架。

- GLB 中的动画为局部变换动画，按普通覆盖动画播放；不要把它们直接作为叠加姿态再加到当前旋转上。
- 保留旋转和位移曲线。FPS 持枪动画含左臂摆位曲线，角色动画也含身体位移；只导入旋转会丢失效果。
- 当前模型与动画配套使用即可。骨骼名称匹配之外，也应保持同一批的比例和参考变换。
- 从 Firearm 切换至空手、近战或投掷时，让不再受新动画驱动的节点属性恢复模型原始值，尤其是左肩局部位置，避免残留持枪偏移。过渡期间可由动画混合系统平滑恢复，不要重置仍在播放的动作。
- Idle、Walk、Run、Charge 循环；其余动作单次播放。动作切换可采用短暂交叉淡化。Death 播放结束后保持末帧，不返回站立。
- 全部动画都是原地动作。移动速度、朝向、碰撞和导航由游戏驱动角色外层对象；不要将死亡动作里的 Root 旋转当成角色控制器的世界移动。
- 完整角色无动画时是 T 形参考姿态。角色生成后应进入 Idle；FPS 装备就绪后也应进入对应类别的 Idle，而不是停留在模型默认姿态。

## 5. FPS 动画清单

文件名统一为 `FSA_ANIM_FPS_<类别>_<动作>.anim.glb`。类别与目录对应如下：

| 类别 | 目录 |
| --- | --- |
| Unarmed | `animations/fps/unarmed/` |
| Firearm | `animations/fps/firearm/shared/` |
| Melee | `animations/fps/melee/shared/` |
| Throwable | `animations/fps/throwable/shared/` |

例如，持枪待机的完整路径为 `animations/fps/firearm/shared/FSA_ANIM_FPS_Firearm_Idle.anim.glb`。动画片段名称与文件名一致，但去掉 `.anim.glb` 后缀。

| 类别 | 动作及原始时长（秒） | 播放方式 |
| --- | --- | --- |
| 四个类别各有一套 | Idle 2.40 / Walk 0.90 / Run 0.62 | 循环 |
| Firearm | Fire 0.26 / Reload 1.45 / Bolt 0.62 | 单次 |
| Firearm | Holster 0.42 / Draw 0.42 | 单次 |
| Melee | Attack 0.72 / Holster 0.34 / Draw 0.34 | 单次 |
| Throwable | Throw 0.80 / Holster 0.34 / Draw 0.34 | 单次 |

这对应 Unarmed 3 段、Firearm 8 段、Melee 6 段、Throwable 6 段，共 23 段。Draw 为拿出，Holster 为收起，Bolt 为拉栓。

### 推荐状态衔接

- 普通持枪：Idle / Walk / Run → Fire → 返回当前移动状态。连发射速由武器配置决定，0.26 秒的视觉动作时长不等同于强制射击间隔。
- 本项目 DMR、SR：Fire → Bolt → 返回当前移动状态；下一次开火需等待项目的拉栓状态允许。
- 换弹：进入 Reload，在弹药提交点更新弹药，动作结束后返回当前移动状态。
- 换装备：旧类别 Holster 完成 → 移除旧武器 → 新武器挂 `Weapon_R` → 新类别 Draw → 新类别 Idle / Walk / Run。不要在 Holster 与 Draw 之间重置双臂为默认姿态。
- 切为空手：旧类别 Holster 完成 → 移除武器 → 淡入 Unarmed。空手没有 Draw/Holster，空手切入装备时挂载新武器并衔接对应 Draw。
- 投掷：Throw 到释放点时移除手中物体并生成世界投射物；有剩余物品时由游戏决定何时补充并播放 Draw，否则转入空手或其他装备。

### FPS 动画事件约定

以下时刻均以 **1 倍速、当前动作开始后经过的秒数**计算，供游戏配置事件使用；GLB 不会自动执行这些玩法操作。改变播放速度时按动画本地时间触发，而不是使用固定现实时间延迟。

| 动作 | 时刻（秒） | 游戏处理 |
| --- | ---: | --- |
| Firearm / Fire | 0.00 | 开火判定、消耗弹药、射线或投射物、音效和枪口效果 |
| Firearm / Reload | 1.18 | 提交换弹结果，一次性更新弹药 |
| Firearm / Bolt | 0.40 | 上膛就绪标记；完整动作在 0.62 秒结束 |
| Melee / Attack | 0.28～0.43 | 开启并关闭近战命中窗口 |
| Throwable / Throw | 0.38 | 隐藏或移除手持手雷，按 Weapon_R 当前世界位置生成投射物并赋予投掷速度 |
| 任意装备 / Holster | 动作末尾 | 卸下旧装备，进入切换阶段 |
| 任意装备 / Draw | 0.00 | 确认新装备已挂载 |

每次播放每个事件只触发一次；时间跨过事件点时也要触发，不能要求浮点时间恰好相等。动作中断、重复输入、弹药不足和死亡时，由游戏明确取消或保留已经提交的操作。近战命中窗口内建议对同一目标去重。

## 6. 角色共用动画

`animations/characters/shared/` 包含十段可复用角色动画，包括法师投掷 Cast 和弓箭发射 Shoot。片段名为文件名去掉 `.anim.glb` 后缀；Cast、Shoot 统一使用 FSA_ANIM_Character_Cast / FSA_ANIM_Character_Shoot，不绑定具体角色。通用 Charge 可按技能配置循环。

| 动作 | 时长（秒） | 循环 | 用途 |
| --- | ---: | --- | --- |
| Idle | 2.40 | 是 | 日常站立、轻微呼吸 |
| Walk | 1.15 | 是 | 行走 |
| Run | 0.72 | 是 | 跑步 |
| Attack | 1.10 | 否 | 右手主导的挥击，空手或丧尸 B 的持斧动作共用 |
| Hit | 0.65 | 否 | 头部与手臂受击反应 |
| Death | 1.60 | 否 | 向后倒地，保持末帧 |
| Interact | 1.80 | 否 | 点头、伸手示意，可用于罗德交互 |
| Charge | 1.20 | 是 | 中性双臂蓄力，可持续循环并在受击时中断 |

Attack 和 Hit 的下半身保持稳定。攻击命中可先配置在约 **0.46 秒**，交互反馈可先配置在约 **0.80 秒**；这两个时刻是接入建议，由项目结合判定范围和交互流程调整。

角色生成后进入 Idle，移动时切 Walk/Run；Attack、Hit、Interact 完成后返回当前活动状态。进入 Death 后停止普通行为切换，并保持倒地姿态，尸体移除时间由游戏决定。

可复用远程片段（以下为 A4、B3 接入示例）：`FSA_ANIM_Character_Cast.anim.glb` 为 1.12 秒，建议在本地 0.92 秒由 `Fireball_Muzzle` 发射火球；`FSA_ANIM_Character_Shoot.anim.glb` 为 0.88 秒，建议在本地 0.71 秒由 `Arrow_Muzzle` 发射箭矢，并隐藏模型内的 `Arrow_Nocked`，下次射击前恢复。两段均为单次原地动作，发射与状态伤害由游戏执行。

## 7. 游戏项目需自行配置的内容

本批提供模型、材质、挂接点和视觉动画。以下由游戏项目配置：碰撞体、角色控制器、导航、血量、伤害、射速、弹药、命中范围、音效、特效、交易界面及投射物物理。

武器只约定主握原点，没有约定独立枪口或抛壳插槽。枪口火焰、出弹位置和抛壳位置可按武器类型在游戏配置中添加局部偏移；不要把 Weapon_R 的手部位置直接作为所有枪型的枪口位置。

初次接入时确认：装备随右手移动，切换类别后左臂位置能恢复，投掷释放后手中物体消失，角色动画绑定到正确模型，Death 结束后不会重新站起。以上行为配置完成后，即可按各武器和角色的玩法参数继续扩展。
