# 实心环境物件 · solid

先读 [公共规范](../ENVIRONMENT_RULES.md)。适用于不可进入的小站、报废车辆、石头、枯树等。

- 提供清楚的落地原点、外观尺寸、生成预留范围和一个或多个简化 Box 碰撞节点。碰撞节点引用模型中的结构 Part，允许多个盒组合，不能只给美术外观。
- 不声明室内通路或物资投放区，不假装可进入建筑。若外观有足以误导玩家的敞开门洞，应封闭或改为 building 类型。
- 不影响通行的装饰可不参与碰撞，但占地预留要容纳它们；伸出的枝条、车镜等不得侵入相邻建筑已验收的入口通道。
- 摆放时只做 Y 轴旋转，坡地优先用平台或适度埋入基础，不能把整体倾斜碰撞未经检查地套用。v1 通行量规不支持任意横滚的实心碰撞。
- 实心物件不是自动可攀登物，顶面不会加入 walkables。

样件为低细节报废运输卡车，用车架、驾驶室、货箱和轮部结构组成碰撞。它用于检查尺度、占地、阻挡和源/产物关系，不代表正式车辆美术质量标准。验收时关闭碰撞线框看外观，再打开检查是否有隐形大墙或可穿越的显著实体。

2026-10-06：岩石视觉可用 model.v1 的 rock 基元（明确 size 和 seed）生成确定性不规则凸体；几何由共用编译器生成，仍禁止原始顶点输入和环境 Part 缩放。碰撞继续引用内嵌 Box 结构并按高度分段，不能把 rock 基元直接登记为 Box 碰撞，也不能以预留矩形代替岩石轮廓。岩石尖角和小凹边存在简化容差，交付时在实际 GLB 上叠加检查。
