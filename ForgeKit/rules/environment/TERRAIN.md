# 地形 · terrain

2026-10-06 地表配色扩展：可选 `terrain.surface="desert-mottled"`，以固定种子的周期多尺度色斑、细碎明暗和高度偏色生成标准 GLB `COLOR_0` 顶点色。沙色、灰褐土色、赭色渐变烘焙在模型中；材质使用白色基色、vertexColors、roughness=1，无外部贴图或自定义着色器依赖。不改顶点位置、法线、碰撞、高度查询或平台参数。省略字段保持旧版纯沙色；同尺寸/种子、零高度边缘的四类正式地块颜色可衔接。

先读 [公共规范](../ENVIRONMENT_RULES.md)。v1 为连续规则高度场，适用于缓坡荒漠和建造平台；没有洞穴、悬挑、垂直峭壁或多层支持面。

- `size` 为 X/Z 长度，`cell` 为网格间距；每轴格数必须是 2～256 的整数。`seed/amplitude/wavelength` 控制确定性的低频起伏。
- `platforms` 声明中心、尺寸、高度和过渡带宽度。建筑的整个 reservation 应放在平台内；不能只检查地基中心。平台及过渡带不得越界或相互重叠，避免后一个平台改坏前一个。
- `maxSlopeDegrees` 是实际三角面最大坡度，编译时检查，不只是噪声参数。可通行路径另按 profiles 的坡度限制验证。
- GLB 和导出高度数组来自同一次生成。数组以 Z 行、X 列存储；网格每格使用 `(a,c,d)` 和 `(a,d,b)`，采样使用相同三角形插值，禁止改用双线性插值。
- 地形由受控生成器产出网格，不扩大原 `model.v1` 允许手写 vertices/indices 的范围。

样件是 48×48m 荒漠、1m 网格、20×24m 平整建造平台，周围有缓坡；统一基础沙色材质。复杂地表分层、道路贴合和材质区域混合尚未提供专用流水，后续美术项可先增加视觉材质方案，不能因此改变碰撞高度。预览的碰撞开关显示真实三角网格。

验收需检查高度/法线与 GLB 一致、平台平整、坡度不过限、同种子重现，以及平台与建筑入口实际衔接。普通建筑取消外加坡板，平台必须使入口最终高差不超过 10cm；特殊高台另行验证衔接结构。当前只做单块样件，未实现无限地形或跨块自动接缝。

2026-10-06 正式荒漠扩展：terrain 可选 `landform=flat|slope|basin|hill`，分别生成微起伏、X 向缓坡、椭圆浅洼和低丘；amplitude 为地貌尺度，seed/wavelength 控制附加低频起伏。省略保持原样件算法。可选 `edgeBlend` 指定收至 y=0 的边缘过渡宽度，最外一格保持全平，平台连同过渡区不得与边缘带重叠。字段纳入严格 schema，不支持手写顶点。正式四块为 112×112m、1m 网格、相同沙色，按 112m 网格平移可使边缘高度与边界法线一致；这是资源约定，不是地图生成实现。不同尺寸、cell、高度基准或任意地形仍需另外处理接缝。
