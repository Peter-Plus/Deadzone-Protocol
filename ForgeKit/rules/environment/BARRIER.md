# 静态围挡 · barrier

先读 [公共规范](../ENVIRONMENT_RULES.md)。适用于铁墙、护栏、封闭边界的直段和转角段，不承担开门动画。

2026-10-06：隔离区采用断续分布的通透铁栏，不要求闭合；特别保护区使用不透明铁墙，形成封闭外围，仅留两扇交互门。两类均阻挡角色和子弹，铁栏视觉缝隙不能成为射击孔，应记录连续的阻挡范围供运行时消费。外围建议用直段、转角和门段拼成尺寸可变的矩形；拼接资源不等于程序生成已实现。

- 结构按 barrier 声明碰撞，至少两个连接点。
- 连接点提供局部位置、水平单位向外方向、墙高和厚度；相邻段的位置吻合、方向相反、墙高和厚度一致。`connectorsMatch()` 检查匹配，容差默认 1cm。
- 允许接缝处立柱轻微重叠，但不能出现可穿越断口或伸入通路的凸块。不能仅凭连接点匹配就免做组合预览与碰撞检查。
- v1 围墙保持竖直；先由地形平台处理基础，或制作独立阶梯高度变体。不可直接拉伸围墙去贴任意坡面。
- 保护区最终闭合边界需在游戏生成中验证，包括坡地绕行和门侧路径；单个墙段通过不等于整圈保护区已封闭。

样件为 6m 主段加 3m 转角段，墙高 4m、板厚 0.25m，包含连接方向标记。与 gate 使用同一高度和厚度契约；拼接实例需统一旋转位置、模型、碰撞和连接点。

2026-10-06 正式围挡：FSA Quarantine 高 2.8m，Protected 高 4m，连续阻挡厚度均为 0.25m。铁栏 `ContinuousBlocker` 是明确声明的 opacity=0 Box，供角色和子弹整段阻挡；它不是可射穿的透明材质规则。运行时必须读取契约碰撞，不能仅射线检测可见栏杆。其余柱、基座、横梁也有保守 Box。直段 6m、转角两臂各 3m、收边 1m；连接高/厚只能在同套资源内匹配。

`*.assembly.json` 使用独立 `environment-preview-assembly.v1`，记录静态 barrier 实例的 asset、position、yaw（度）及 gateSlots 门位标注。环境 build 将它们嵌入同一个离线预览并复制到 references，不导出整圈正式模型，不加入模型清单。这是制作参考，游戏尚无该组装格式消费器。门位标线不是门框/门扇实物，保护区大门由独立门项提供后再验证动态装配。
